# ToolKeeper｜工具番

ToolKeeper（工具番）是一個以「超好用的小工具」為核心的 Windows 軟體品牌與 Launcher。

原則：

- 小而專一
- 開啟就能用
- 不增加工作流程，只刪除工作流程
- 低價、低維護、離線優先
- 每個工具都是獨立 App
