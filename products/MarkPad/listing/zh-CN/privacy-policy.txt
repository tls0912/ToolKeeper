汗青 - Markdown Writer 隐私政策
更新日期：2026 年 10 月 4 日
发布者：不告訴你

1. 文档与本地处理
汗青读取您选择打开的 Markdown 文档、相关文件路径，以及文档引用且获准读取的本地图片，用于编辑、预览、保存和 PDF 导出。这些内容可能包含您自行写入的个人信息。本应用没有将文档或 PDF 上传到发布者服务器的功能，也不要求创建汗青账户。

2. 本地保存的数据
为提供日常功能，应用会在当前 Windows 用户的应用数据区域保存语言、主题、字体等设置、最近打开的文件路径、未保存文档的恢复草稿、错误日志、WebView2 的本地数据和已确认正式许可证的记录。如果启用关闭时记住文件，还会保存已命名文档的路径及当前活动文档，以便下次启动时重新打开；关闭该选项会清除这一列表。内置阅读文章的轮换位置也会保存在本地。草稿可能包含文档全文；错误日志可能包含文件路径和异常信息。汗青不会自动将这些数据发送给发布者。关闭自动保存仍会创建恢复草稿。最近文件列表最多保存 20 条路径，错误日志会轮换保存，没有固定的保留天数。其他本地数据可能跨会话保留，直到应用清理或由您删除。

3. Microsoft 服务
商店版通过 Microsoft Store 确认许可证，读取许可证是否有效、是否为试用以及到期信息。正式购买经确认后，应用使用 Windows 用户保护机制保存本地确认记录，供后续启动使用。账户登录、购买和付款由 Microsoft 处理，汗青不要求或保存 Microsoft 账户密码或信用卡信息。预览和 PDF 导出使用 Microsoft Edge WebView2 Runtime。Microsoft Store、Windows 和 WebView2 自身的服务及诊断数据处理适用 Microsoft 隐私声明：https://privacy.microsoft.com/privacystatement

4. 链接、网络与分享
文档预览会阻止远程图片和文档内容发起的网络请求。点击网页链接时，应用会交由系统默认浏览器打开，目标网站可能按其政策处理数据。复制文本、链接或电子邮件地址会使用 Windows 剪贴板；剪贴板历史记录或同步取决于您的 Windows 设置。选择前往商店会打开本产品的 Microsoft Store 页面。如果您自行将文档存入网络位置或云同步文件夹，该服务可能另外处理文件。本应用未内置广告或使用行为分析跟踪功能。

5. 您的控制与数据安全
您可以自行查看、修改或删除保存的文档和导出的 PDF，并在应用设置中调整偏好和自动保存。“重置设置”会重置偏好、最近文件列表、记住的已打开文件列表和文章轮换位置，不会删除文档、草稿、日志、WebView2 数据或许可证记录。关闭应用后，可以管理或删除汗青自身的本地设置、草稿、日志、WebView2 数据和许可证记录；删除草稿会失去相应的恢复内容，删除许可证记录会使下次启动重新确认许可证。汗青未对文档、设置、草稿和日志另行加密；请使用适当的 Windows 访问权限和设备保护。发布者无法通过汗青远程访问或代为删除您电脑上的数据。

6. 政策更新
数据处理方式变化时，本政策将相应更新。
