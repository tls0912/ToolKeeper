汗青 - Markdown Writer，让阅读与写作回到文档本身。打开本地 Markdown 文档，先查看清晰排版的预览，再切换到编辑模式；适合阅读 README、整理笔记和撰写说明。

阅读时，左侧章节列表自动整理 H1–H6 标题，点击即可跳到对应段落。你可以选择要显示的标题级别，同一设置也会应用到导出 PDF 的章节书签。编辑时，在左侧编写 Markdown，在右侧查看实时预览，同时对照原文与排版。通过多个标签页切换文档，用搜索与替换修改内容。

提供亮色、深色、竹子（亮色）和竹子（深色）四种主题；竹子界面搭配宣纸底色，营造不同明暗的阅读体验。可以分别调整界面、预览和编辑器的字体及字号，选择传统文字风格或电脑上已安装的字体。编辑工具栏可插入标题、粗体、斜体、删除线、行内代码和链接。

支持表格、任务列表、代码块、脚注和本地图片。需要分享成品时，先保存 Markdown，再在原文件所在文件夹导出带时间戳的 PDF。自动保存、外部修改提示和崩溃后的草稿恢复，也可辅助日常文档工作。

可选择在关闭时记住已打开的文档，下次启动时重新打开已命名的文件；未保存的内容仍需按提示处理。没有打开文档时，三篇内置阅读文章会在每次进入无文档界面时依次轮换，阅读过程中不会自动换篇。

文档处理和预览均在本地完成。界面和三篇内置文章均提供繁体中文、英语、日语、简体中文、西班牙语、阿拉伯语、法语和韩语八种语言。

提供 7 天免费试用，试用期限和许可证由 Microsoft Store 管理。试用到期后，需要一次性购买正式版才能继续使用。

预览和 PDF 导出需要 Microsoft Edge WebView2 Runtime。
