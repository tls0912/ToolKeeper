1. 문서 및 로컬 처리
Hanqing은 편집, 미리 보기, 저장, PDF 내보내기를 위해 사용자가 열도록 선택한 Markdown 문서, 관련 파일 경로, 문서에서 참조하는 허용된 로컬 이미지를 읽습니다. 이 콘텐츠에는 사용자가 문서에 입력한 개인정보가 포함될 수 있습니다. 앱에는 문서나 PDF를 게시자의 서버에 업로드하는 기능이 없으며, Hanqing 계정이 필요하지 않습니다.

2. 기기에 저장되는 데이터
앱은 현재 Windows 사용자의 앱 데이터 영역에 언어, 테마, 글꼴 등의 환경 설정, 최근 파일 경로, 다시 열기 옵션을 켠 경우 열린 문서의 경로, 저장하지 않은 문서의 복구용 초안, 오류 로그, WebView2 로컬 데이터, 정식 라이선스 확인 기록을 저장합니다. 내장 글의 순환 위치도 저장하며, 열린 파일 기억 기능을 켜면 활성 문서도 기록합니다. 이 옵션을 끄면 저장된 파일 목록이 지워집니다. 초안에는 문서 전체 내용이 포함될 수 있으며, 오류 로그에는 파일 경로와 예외 세부 정보가 포함될 수 있습니다. Hanqing은 이러한 파일을 게시자에게 자동으로 전송하지 않습니다. 자동 저장을 꺼도 복구용 초안은 생성됩니다. 최근 파일은 경로 20개로 제한되며, 오류 로그는 정해진 보관 기간 없이 순환 관리됩니다. 그 밖의 로컬 데이터는 앱이 정리하거나 사용자가 삭제할 때까지 앱을 다시 실행한 뒤에도 남아 있을 수 있습니다.

3. Microsoft 서비스
Microsoft Store 버전은 라이선스를 확인하고 활성 상태, 체험판 여부, 만료 정보를 읽습니다. 정식 버전 구매가 확인되면 현재 Windows 사용자를 위해 보호된 로컬 확인 기록을 저장하여 이후 실행에 사용합니다. 계정 로그인, 구매, 결제는 Microsoft가 처리합니다. Hanqing은 Microsoft 계정 비밀번호나 신용카드 정보를 요청하거나 저장하지 않습니다. 미리 보기와 PDF 내보내기에는 Microsoft Edge WebView2 Runtime을 사용합니다. Microsoft Store, Windows, WebView2의 서비스 및 진단 데이터 처리에는 Microsoft 개인정보처리방침이 적용됩니다: https://privacy.microsoft.com/privacystatement

4. 링크, 네트워크 및 공유
문서 미리 보기는 원격 이미지와 문서 콘텐츠에서 발생시키는 네트워크 요청을 차단합니다. 웹 링크를 클릭하면 기본 브라우저가 열리며, 대상 웹사이트는 자체 정책에 따라 정보를 처리할 수 있습니다. 텍스트, 링크, 이메일 주소를 복사할 때는 Windows 클립보드를 사용합니다. 클립보드 기록 및 동기화는 Windows 설정에 따라 달라집니다. 스토어 방문을 선택하면 이 제품의 Microsoft Store 페이지가 열립니다. 네트워크 위치나 클라우드와 동기화되는 폴더에 문서를 저장하면 해당 서비스가 파일을 별도로 처리할 수 있습니다. 앱에는 광고나 사용 분석을 위한 추적 기능이 내장되어 있지 않습니다.

5. 사용자 제어 및 데이터 보안
저장한 문서와 내보낸 PDF를 확인, 편집, 삭제할 수 있으며, 앱에서 환경 설정과 자동 저장을 변경할 수 있습니다. 설정 초기화는 환경 설정을 기본값으로 되돌리고 최근 파일 목록 및 다음 실행 시 다시 열 파일 목록을 지우지만, 다른 데이터는 삭제하지 않습니다. 앱을 닫은 뒤 Hanqing의 로컬 환경 설정, 초안, 로그, WebView2 데이터, 라이선스 기록을 관리하거나 삭제할 수 있습니다. 초안을 삭제하면 복구 내용이 제거되며, 라이선스 기록을 삭제하면 이후 실행 시 라이선스를 다시 확인해야 합니다. Hanqing은 문서, 환경 설정, 초안, 로그를 별도로 암호화하지 않습니다. 적절한 Windows 접근 제어와 기기 보호 기능을 사용하세요. 게시자는 Hanqing을 통해 사용자 컴퓨터의 파일에 원격으로 접근하거나 삭제할 수 없습니다.

6. 방침 변경
앱의 데이터 처리 방식이 변경되면 이 방침을 갱신합니다.
