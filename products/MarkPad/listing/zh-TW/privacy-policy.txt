汗青 - Markdown Writer 隱私權原則
更新日期：2026 年 9 月 28 日
發行者：不告訴你

1. 文件與本機處理
汗青讀取您選擇開啟的 Markdown 文件、相關檔案路徑，以及文件引用且獲准讀取的本機圖片，用於編輯、預覽、儲存及 PDF 匯出。這些內容可能包含您自行寫入的個人資訊。本程式沒有將文件或 PDF 上傳至發行者伺服器的功能，也不要求建立汗青帳號。

2. 本機保存的資料
為提供日常功能，程式會在目前 Windows 使用者的應用程式資料區保存語言、風格、字型等設定、最近開啟的檔案路徑、未儲存文件的復原草稿、錯誤日誌、WebView2 的本機資料及已確認正式授權的紀錄。草稿可能包含文件全文；錯誤日誌可能包含檔案路徑與例外訊息。這些資料不會由汗青自動回傳給發行者。關閉自動儲存仍會建立復原草稿。最近檔案清單最多保存 20 筆，錯誤日誌會輪替而沒有固定保留天數。其餘本機資料可能跨工作階段保留，直到程式清理或由您刪除。

3. Microsoft 服務
商店版透過 Microsoft Store 確認授權，讀取授權是否有效、是否為試用及到期資訊。正式購買經確認後，程式使用 Windows 使用者保護機制保存本機確認紀錄，供後續啟動使用。帳號登入、購買與付款由 Microsoft 處理，汗青不要求或儲存 Microsoft 帳號密碼或信用卡資料。預覽與 PDF 匯出使用 Microsoft Edge WebView2 Runtime。Microsoft Store、Windows 與 WebView2 自身的服務及診斷資料處理適用 Microsoft 隱私權聲明：https://privacy.microsoft.com/privacystatement

4. 連結、網路與分享
文件預覽會阻擋遠端圖片與文件發起的網路請求。您點選網頁連結時，程式會交由系統預設瀏覽器開啟，目的網站可能依其政策處理資料。複製文字、連結或電子郵件地址會使用 Windows 剪貼簿；剪貼簿歷程或同步取決於您的 Windows 設定。選擇前往商店會開啟本產品的 Microsoft Store 頁面。若您自行將文件存入網路或雲端同步資料夾，該服務可能另外處理檔案。本程式未內建廣告或使用行為分析追蹤功能。

5. 您的控制與資料安全
您可自行查看、修改或刪除儲存的文件與匯出 PDF，並在程式設定中調整偏好及自動儲存。「重設設定」只重設偏好與最近檔案清單，不會清除其他資料。關閉程式後，可管理或刪除汗青自己的本機設定、草稿、日誌、WebView2 資料與授權紀錄；刪除草稿會失去相應復原內容，刪除授權紀錄會使下次啟動重新確認授權。汗青未替文件、設定、草稿與日誌另行加密；請使用適當的 Windows 存取權限與裝置保護。發行者無法透過汗青遠端存取或代為刪除您電腦上的資料。

6. 原則更新
資料處理方式變更時，本原則將相應更新。
