汗青 - Markdown Writer プライバシーポリシー
更新日：2026 年 9 月 28 日
発行者：不告訴你

1. 文書とローカル処理
汗青は、編集、プレビュー、保存、PDF 出力のために、ユーザーが選んで開いた Markdown 文書、そのファイルパス、文書から参照され読み込みが許可されたローカル画像を読み取ります。文書にはユーザー自身が記載した個人情報が含まれる場合があります。本アプリには文書や PDF を発行者のサーバーへアップロードする機能はなく、汗青専用アカウントの作成も不要です。

2. 端末に保存するデータ
言語、テーマ、フォントなどの設定、最近開いたファイルのパス、未保存文書の復元用下書き、エラーログ、WebView2 のローカルデータ、確認済みの製品版ライセンス記録を、現在の Windows ユーザーのアプリデータ領域に保存します。下書きには文書の全文、ログにはファイルパスや例外の詳細が含まれる場合があります。汗青がこれらを発行者へ自動送信することはありません。自動保存を無効にしても、復元用下書きは作成されます。最近のファイルは最大 20 件のパスを保存し、エラーログは固定の保存日数を設けずにローテーションします。その他のローカルデータは、アプリによる整理またはユーザーによる削除まで、セッションをまたいで残る場合があります。

3. Microsoft のサービス
Store 版は Microsoft Store を通じてライセンスを確認し、有効性、試用版かどうか、有効期限の情報を読み取ります。製品版の購入が確認されると、現在の Windows ユーザー向けに保護された確認記録をローカルに保存し、以後の起動に使用します。アカウントへのサインイン、購入、支払いは Microsoft が処理します。汗青は Microsoft アカウントのパスワードやクレジットカード情報を要求・保存しません。プレビューと PDF 出力には Microsoft Edge WebView2 Runtime を使用します。Microsoft Store、Windows、WebView2 自身のサービスや診断データの取り扱いは Microsoft のプライバシーステートメントに従います：https://privacy.microsoft.com/privacystatement

4. リンク、通信、共有
文書のプレビューでは、リモート画像と文書からのネットワーク要求を遮断します。Web リンクを選ぶと既定のブラウザーで開き、リンク先のサイトは独自のポリシーに基づいてデータを処理する場合があります。テキスト、リンク、メールアドレスのコピーには Windows のクリップボードを使用し、その履歴や同期は Windows の設定に従います。ストアへ移動する操作では、本製品の Microsoft Store ページを開きます。文書をネットワーク上やクラウド同期フォルダーに保存した場合、そのサービスが別途ファイルを処理する場合があります。本アプリには広告や利用状況を追跡する分析機能を組み込んでいません。

5. ユーザーによる管理と安全性
保存した文書や出力した PDF は、ユーザー自身で閲覧、変更、削除できます。アプリの設定で各種設定や自動保存を変更できます。設定のリセットは設定と最近のファイル一覧だけを対象とし、その他のデータは消去しません。アプリを終了した後、汗青自身のローカルの設定、下書き、ログ、WebView2 データ、ライセンス記録を管理・削除できます。下書きを削除すると対応する復元内容が失われ、ライセンス記録を削除すると次の起動時に再確認が必要になります。汗青は文書、設定、下書き、ログに独自の暗号化を追加していません。適切な Windows のアクセス権と端末保護を使用してください。発行者は汗青を通じて端末内のファイルに遠隔アクセスしたり、代わりに削除したりできません。

6. ポリシーの更新
データの取り扱いが変わる場合は、本ポリシーを更新します。
