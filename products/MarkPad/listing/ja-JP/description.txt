汗青 - Markdown Writer は、Markdown の閲覧と編集に集中できる Windows アプリです。ローカルのファイルを読みやすいプレビューで開き、変更したいときに編集へ切り替えられます。README、メモ、説明文などの作成に役立ちます。

閲覧モードでは、左側の章一覧に H1–H6 の見出しを自動表示。クリックすると目的の段落へ移動できます。編集モードでは、左側で Markdown を書きながら、右側のライブプレビューで仕上がりを確認できます。複数のファイルをタブで切り替え、検索と置換で文章を整えられます。

竹のライト／ダークテーマに、宣紙の風合いを組み合わせた画面。画面全体、プレビュー、エディターのフォントと文字サイズを個別に設定でき、伝統書体やパソコンにインストールされているフォントを選べます。編集ツールバーから、見出し、太字、斜体、取り消し線、インラインコード、リンクも挿入できます。

表、タスクリスト、コードブロック、脚注、ローカル画像に対応。完成した文章は Markdown を保存してから、元のファイルと同じフォルダーに日時付きの PDF として書き出せます。自動保存、外部での変更通知、クラッシュ後の下書き復元も利用できます。

文書の処理とプレビューはローカルで行います。画面の言語は繁体字中国語、英語、日本語に対応しています。

7 日間の無料試用を利用できます。試用期間とライセンスは Microsoft Store が管理します。試用期間終了後も使い続けるには、製品版を買い切りで購入してください。

プレビューと PDF 出力には Microsoft Edge WebView2 Runtime が必要です。
