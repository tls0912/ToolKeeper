汗青 - Markdown Writer は、Markdown の閲覧と編集に集中できる Windows アプリです。ローカルのファイルを読みやすいプレビューで開き、変更したいときに編集へ切り替えられます。README、メモ、説明文などの作成に役立ちます。

閲覧モードでは、左側の章一覧に H1–H6 の見出しを自動表示。クリックすると目的の段落へ移動できます。表示する見出しレベルを選べ、その設定は出力する PDF のしおりにも適用されます。編集モードでは、左側で Markdown を書きながら、右側のライブプレビューで仕上がりを確認できます。複数のファイルをタブで切り替え、検索と置換で文章を整えられます。

ライト、ダーク、竹のライト、竹のダークの 4 つのテーマを用意。竹のテーマでは宣紙の風合いを楽しめます。画面全体、プレビュー、エディターのフォントと文字サイズを個別に設定でき、伝統書体やパソコンにインストールされているフォントを選べます。編集ツールバーから、見出し、太字、斜体、取り消し線、インラインコード、リンクも挿入できます。

表、タスクリスト、コードブロック、脚注、ローカル画像に対応。完成した文章は Markdown を保存してから、元のファイルと同じフォルダーに日時付きの PDF として書き出せます。自動保存、外部での変更通知、クラッシュ後の下書き復元も利用できます。

設定を有効にすると、終了時に開いていた名前付きファイルを記憶し、次回起動時に開き直せます。未保存の変更は、通常どおり保存確認で処理します。文書を開いていない画面では、内蔵された 3 編の記事を順番に表示。その画面に入るたびに次の記事へ進み、読んでいる途中には切り替わりません。

文書の処理とプレビューはローカルで行います。画面と 3 編の内蔵記事は、繁体字中国語、英語、日本語、簡体字中国語、スペイン語、アラビア語、フランス語、韓国語の 8 言語に対応しています。

7 日間の無料試用を利用できます。試用期間とライセンスは Microsoft Store が管理します。試用期間終了後も使い続けるには、製品版を買い切りで購入してください。

プレビューと PDF 出力には Microsoft Edge WebView2 Runtime が必要です。
