# CabiDock

002 的獨立 .NET 10／WPF 開發原型。

```powershell
dotnet run --project src/CabiDock/CabiDock.csproj
```

啟動後顯示設定視窗；「開啟群組操作預覽」可操作桌面項目的虛擬分類。群組目前位於一般預覽視窗，原生桌面圖示保留，尚未完成桌面接管。關閉設定視窗縮至系統匣，從系統匣「結束程式」退出。
