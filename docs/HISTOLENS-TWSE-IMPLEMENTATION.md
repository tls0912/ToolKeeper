## 使用方式

1. 開啟 [006 隔離預覽](../artifacts/histolens-preview/Start-HistoLens.cmd)。
2. 輸入現行上市普通股代碼及下載起訖日，例如 `2330`、`2025-01-01` 至 `2025-03-31`；這組例子只用於說明操作。
3. 按「下載官方資料」。完成後立即顯示來源與資料品質，「原始日線行情」可查看 OHLC、股數及交易狀態。
4. 選研究模板與參數，按「執行研究」。查看統計、案例及排除原因後，可保存這次完整研究。
5. 下次從「已保存行情」或「開啟行情檔案」離線載入資料，亦可直接重開完整研究。

不需要註冊帳號或 API Token；僅在按下載時連線。開啟軟體、切換模板及執行既有資料研究不會自動下載。合成示範仍可使用，畫面明確區分合成與 TWSE 資料。

## 支援範圍與取得規則

- 先限定現行 TWSE 上市普通股：ISIN 名錄的 `Stocks` 區段、`TWSE LISTED` 市場及 `ESVUFR` CFI，並交叉核對上市公司基本資料的代號與上市日。ETF、特別股、TDR、上櫃及不在現行名錄的證券不納入。
- 下載日期不早於 2011-01-01 或該證券上市日；單次最多十年，結束日最晚為台灣時間昨天。當日資料不下載。
- 日線按月取得 `STOCK_DAY`；市場交易日由獨立的 `FMTQIK` 市場成交月報取得，不能由個股缺日或一般工作日推算。
- 原始價格以 TWD、成交量以股保存。不補價、不把停牌或缺日跳過、不自行還原價格。
- TWSE 回傳零成交股數時，即使仍有 OHLC 參考值也標示 `NoTrading`，保留原值並排除涉及該日的研究窗口；不改寫通用核心對明確指定 `Traded` 的既有政策。
- 每次 HTTP 請求有 3 秒節流、30 秒逾時、大小上限及取消；遇到 429 不連續重試。一般回應上限 8 MiB，實測較大的 ISIN 名錄上限 16 MiB。
- 0.3.1 起，下載前按日比對本機資料，只請求含缺漏日期的月份，回應中已有的有效日線保留。行情改為同一股票一份檔案，原子合併補齊；既有研究檔中的快照保持不變。背景自動更新與不同資料修訂比較尚未實作。

## 公司行動與原價可比性

`TWT49U`、`TWTAUU`、`TWTB8U` 補充除權息、減資、面額變更，但目前不足以宣稱完整公司行動目錄。因此正式下載的 `ActionCoverage.IsVerified` 保持 `false`。

另設 `PriceComparisonCoverage`，按官方日線的漲跌價差及不比價定義逐日驗證原價可比性：

- 對照相鄰的市場交易日，檢查數字價差是否等於當日收盤減前日收盤。
- `X`、`**`、未知註記／價差、差額不一致及缺必要行情，形成不可跨越邊界；沒有已知前收的首個市場日保留缺口。
- 原價研究窗口必須有完整公司行動覆蓋，或有已核對的原價可比性覆蓋；兩者均不足時不能研究。已知公司行動及不比價邊界仍一律排除。
- 不把 `X0.00` 當普通零價差，不把查不到事件當不存在。這套結果是原始價格變化，並非含股利再投資的總報酬。

引擎版本為 `0.2.0-twse-preview`。新增可比性來源、版本、範圍與缺口進入快照指紋，研究也保存對應版本。舊合成檔的新增欄位為 null 時不序列化，維持舊指紋相容。

## 保存與失敗行為

- 行情位於產品資料目錄的 `market-data/*.twse-data.json`；研究仍位於 `research/*.histolens.json`。隔離預覽的根目錄為 `artifacts/histolens-preview/profile/toolkeeper-host/HistoLens/`。
- 即使研究被阻擋，仍可保存未完整覆蓋的行情供離線查看。行情與研究檔均有版本、內容校驗、結構檢查及 64 MiB 上限。
- 寫入採背景工作、暫存檔與完成後改名。每次快照獨立命名，成功落盤後才替換畫面資料。
- 下載／開啟失敗、取消、輸入修改或關窗，不讓延遲結果覆蓋目前工作。
- 校驗碼用於檢查內容一致性，並非官方簽章。軟體不會將使用者股票代碼以外的本機研究或偏好上傳。
