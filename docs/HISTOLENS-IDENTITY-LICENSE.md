11425 的市場分布：上市 36,318、上櫃 12,363、興櫃 365、未上市櫃 85、終止上市櫃 95,730。已實際見到 `0050 元大台灣50`、`00679B 元大美債20年` 等 ETF，以及大量終止記錄；這不是純普通股清單，也**不是只有仍存續證券**。未提供獨立證券種類欄，不能只依代碼長度或名稱可靠排除非普通股。

## 3. 業務規則、授權依據與驗收條件

### 3.1 實際開放資源的權利

上述精確 data.gov 下載資源在各自資料集頁均明載「政府資料開放授權條款－第 1 版」、免費。對應 API 的依據是資料集備註的官方 OAS 導引，再以精確路徑與資料識別核對；並非只因同一機構或網域便套用授權。

[OGDL-1](https://data.gov.tw/license) 第 2 條授予不限用途、時間、地域的免授權金利用，包含重製、散布、傳輸、編輯、改作及產品衍生物；可再授權且無須另取書面授權。第 3 條要求資料及衍生物遵守顯名義務；不涵蓋專利與商標。資料提供可停止，亦不保證正確或完整。以下是這些文字對 HistoLens 使用情境的對應，限已確認釋出的資料。

| 使用情境 | 已確認開放資源的判定 | 工程驗收對應 |
| --- | --- | --- |
| 付費桌面軟體使用 | 第 2 條不限目的及產品衍生物，未列商用另付授權金條件 | 來源頁及輸出附顯名；不宣稱機構背書 |
| 使用者電腦直接下載 | 開放資源供公眾取得；資料利用權有依據 | 公開端點序列低量請求；自動請求的限流、可用率與服務承諾仍須獨立驗證 |
| 本機快取與長期離線保存 | 重製及不限時間的授權支持保存 | 保存來源、資料版本與顯名依據；不能保證未來端點仍持續提供 |
| 顯示原始行情及圖表 | 原始資料與改作利用有依據 | 必須來自已確認開放行情資源；不可把本輪僅驗證識別檔的成果寫成行情已完成 |
| 產生歷史統計 | 編輯、改作與衍生物有依據 | 統計顯示來源、資料期間與限制 |
| 匯出原始資料或統計 | 重製、散布、再授權有依據 | 匯出隨附來源顯名與授權連結；原始價格不可被調整價覆寫 |

顯名內容需包含提供機關／單位、年份、資料名稱與來源有提供的版本，以及 OGDL 聲明與 [授權連結](https://data.gov.tw/license)。版本未提供時記「來源未提供版本號」，另附來源資料日期與取得時間；HTTP ETag 可記錄但不冒稱官方資料集版本號。平臺提供機關是證期局，來源實際單位分別為集保、證交所、櫃買中心，保存兩者避免只標「政府資料」。

### 3.2 其他官方歷史查詢端點

[TWSE 使用條款](https://www.twse.com.tw/zh/terms/use.html) 與 [TPEx 網站使用條款](https://www.tpex.org.tw/zh-tw/gtsm_disclaimer.html?l=zh-tw) 均對一般網站資料保留事先書面同意，且把已授權政府資料開放平臺的資料列為例外。這是網站文字；不能因端點免登入、免費回 HTTP 200 或回傳 JSON，就判為開放授權。

`STOCK_DAY_ALL?response=open_data` 已有 11549 的精確資源證據，不能自動覆蓋 TWSE `STOCK_DAY` 個股逐月歷史查詢。TPEx 的歷史查詢、舊 PHP 加日期參數、新 route 亦不能僅因回傳相同欄位就承接 11370 授權。就本輪已核對文字而言，這些其他歷史資源的六項使用權均**尚未取得足以確認的逐資源開放授權依據**，不直接認定不能取得，也不預設必須付費。本輪不購買、不申請、不轉供。

驗收時，下載能力與使用權分開：資料可下載但權利未確認，標記「已取得／授權待確認」；資料集有開放授權但請求逾時，標記「權利有據／下載未完成」。

## 4. 例外流程及請求量

- 最初 sandbox 拒絕目錄寫入及 socket 請求，屬執行環境權限，沒有源站 HTTP 回應；升權後以相同公開 URL 正常低量直連，沒有換身分、代理、繞過登入或封鎖。
- Web 工具取得 11425 回「Unsupported content-type: text/csv」，直連成功；不是來源資料不可用。兩個 mopsfin CSV 的 Web 路徑及直連均逾時；不能聲稱 CSV 編碼或欄位已實測。
- 兩個備註 OAS API 各直連一次成功。沒有驗證碼、登入、付款步驟，未觀察到 429；單次成功不足以確認大量或長期請求的限流規則。
- 11370 的 Web 工具探測回 403；本節未對其作第二輪下載，不把這個工具路徑失敗描述成源站所有通道均封鎖。
- 本子任務直接 source 資料請求 **5 次**：3 個指定 CSV（1 成功、2 逾時）及 2 個正式 OAS 識別 API（均成功）；後續證據頁 snapshot **6 次**（3 資料集頁、OGDL、TWSE 條款、TPEx 條款）。Web 工具還對 3 個識別 CSV、2 個行情 CSV 各進行一次工具層探測；Web 快取與搜尋內部網路請求量不可確認，未把它冒稱為精確總源站請求數。所有直接請求循序執行。

失敗不寫成功時間，不將空回應覆蓋原始證據；公司主檔的 `Date`／`出表日期` 應由各 Provider 語義處理，不能統一當股票交易日。
