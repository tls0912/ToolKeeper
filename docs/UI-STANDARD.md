# 工具番介面標準

未特別指定時，工具番全系列以工具番本體現有外觀為預設標準。參考 [本體主視窗](../src/ToolKeeper/MainWindow.xaml)、[AppWindow](../src/ToolKeeper.UI/AppWindow.cs) 與 [共用介面開發指南](../src/ToolKeeper.UI/README.md)。此標準統一視窗外觀與一般工具的標頭配置；各產品工作區與業務功能仍依其需求設計。

## 視窗與標頭

- 不顯示 Windows 原生標題列。使用共用 `WindowFrame`，由它設定 `WindowStyle.None` 並處理拖曳、縮放及視窗按鈕。
- 保留工具番的竹紋頂列，顯示完整的 `MainName - SubName` 產品名稱，以及最小化、最大化／還原、關閉按鈕；按鈕依視窗既有 `ResizeMode` 決定可用性。這是自訂頂列，不是 Windows 原生標題列。
- 一般工具使用 `AppWindow`。產品簡介放在標頭左側，「風格／語言／關於」靠右，與簡介位於同一行；簡介可隨寬度換行。
- 內容區不重複顯示大型產品名稱，也不另外建立一套系統標題列或視窗按鈕。需要的產品操作可使用 `HeaderActions`，功能內容放入 `Workspace`。

## 風格與偏好

- 預設使用亮竹子，即 `Ink`；竹紋頂列、外框與紙紋工作面沿用共用元件及資源。
- 保留使用者已保存且有效的風格、語言及字體偏好，不以預設值覆寫。產品既有設定保存方式及同步範圍依原設計保留。

## 已明確指定的配置

汗青保留其文件分頁、側欄、編輯與預覽配置，仍使用共用 `WindowFrame`。一般工具的標頭配置不取代汗青已指定的文件介面。

## 驗收重點

- 視窗上方只有共用自訂頂列，沒有額外 Windows 原生標題列；產品名稱及視窗按鈕沿用工具番本體樣式。
- 一般工具的簡介與右側三個偏好入口同列，內容區沒有重複的大型產品名稱。
- 無既有有效偏好時使用 `Ink`；有有效偏好時仍載入原值。
- 工作區保留各產品所需的功能配置，汗青保留其已指定的文件介面。
