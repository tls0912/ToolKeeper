## 日後有需求再調整

| 產品選擇 | 目前做法／建議 | 何時值得改變 |
| --- | --- | --- |
| 是否直接覆寫原檔 | 保留另存新檔；若加入覆寫，應包含來源變更檢查與復原安排 | 真實使用中頻繁需要替換檔案，且願意接受額外的檔案管理流程 |
| 是否支援大型檔案 | 初版先設合理上限與有限長度預覽 | 常用檔案超過目前上限；再以真實範例決定串流、抽樣與預覽方式 |
| 是否加入批次轉檔 | 暫緩，先確保單檔結果可檢查 | 使用者確實需要大量相同規則轉換，而非偶爾開檔 |
| 額外 Legacy Encoding | 先以常見 Windows／Unicode／亞洲編碼支援核心用途 | 有實際無法處理的設備或系統範例時再補 |

這些是後續擴充方向，現在不需要逐項確認，也不代表已承諾在 V1 全部提供。
