# 006｜HistoLens

更新日期：2026-10-02。產品類型：規劃中／個股歷史研究工具。

HistoLens 中文定位為「歷史放大鏡」。產品核心不是即時看盤、薦股或預測市場，而是讓使用者針對自己有興趣的個股，按需取得歷史資料，透過條件篩選、事件回溯與統計分析，研究該股票過去在相似條件下曾經如何表現。

## 產品定位

- 產品 ID：`006`。
- 正式名稱：`HistoLens`。
- 中文意象：`歷史放大鏡`。
- 核心用途：個股歷史資料研究與統計。
- 使用者自行選擇研究標的；軟體不主動推薦股票。
- 使用者確認研究某檔股票後才下載該標的歷史資料，不預先下載全市場資料。
- 產品只整理與呈現歷史事實、歷史樣本及統計結果，不代替使用者做投資決策。

## 核心流程

1. 使用者搜尋或輸入股票代號。
2. 選擇有興趣的個股。
3. 確認後下載該個股指定期間的歷史資料。
4. 歷史資料保存於本機，後續只更新缺少的日期。
5. 使用者選擇或組合研究條件。
6. HistoLens 掃描歷史資料，找出符合條件的歷史案例。
7. 統計事件發生後 5、10、20、60 個交易日等期間的後續表現。
8. 使用者查看統計分布與實際歷史案例，自行解讀結果。

## 第一階段資料範圍

V1 先以日線歷史資料為主：

- 日期
- 開盤價
- 最高價
- 最低價
- 收盤價
- 成交量
- 成交金額（資料源可提供時）

未來可視需求擴充：

- 法人買賣超
- 融資融券
- 借券
- 月營收
- 財務資料
- 大盤與產業指數
- 其他可合法取得並適合歷史研究的資料

## 歷史研究能力

研究條件可逐步涵蓋：

- 價格位於近期高低點的相對位置
- 連續上漲／下跌天數
- 指定期間漲跌幅
- 成交量相對均量
- 大量／縮量
- 突破前高或跌破前低
- 回檔幅度
- 區間震盪
- 自訂多條件組合

HistoLens 的核心問題是：

- 這個條件在歷史上發生過幾次？
- 發生後 5／10／20／60 日通常怎麼走？
- 平均與中位數報酬是多少？
- 上漲與下跌樣本各有多少？
- 最佳與最差歷史案例是什麼？
- 哪些歷史日期與目前狀況最接近？

## 統計輸出

研究結果預計包含：

- 符合條件的樣本數
- 後續指定期間平均報酬
- 中位數報酬
- 上漲／下跌次數與比例
- 最大漲幅
- 最大跌幅
- 最大回撤
- 報酬分布
- 歷史案例日期列表
- 可點選的個別案例走勢

所有統計應明確標示研究期間、樣本數與條件，避免把歷史統計誤解為未來保證。

## 產品邊界

HistoLens 明確不以以下功能為核心：

- 不提供「買進／賣出」指令
- 不提供目標價
- 不提供今日推薦股
- 不以即時行情看盤為主要用途
- 不自動替使用者選股
- 不將歷史統計包裝成保證性的未來預測
- 不直接執行交易

產品主張是：

> 不告訴你明天會怎樣，把過去攤開給你看。

## 資料策略

- 採 Provider 抽象層隔離資料來源與研究邏輯。
- 優先研究 TWSE、TPEx 等官方資料來源與商業授權方案。
- 使用者選定股票後才取得資料，避免不必要的全市場同步。
- 首次下載完整指定期間；之後只補缺少日期。
- 歷史資料以本機資料庫快取，研究模型不直接依賴特定資料供應商。
- 原始行情只是研究材料，產品價值放在條件研究、歷史案例與統計結果。
- 正式商用前需確認資料來源對下載、快取、顯示及外部使用的授權範圍。

## 初步架構方向

```text
Market Data Provider
        ↓
Historical Data Store
        ↓
Feature / Condition Engine
        ↓
Historical Case Scanner
        ↓
Statistics Engine
        ↓
HistoLens UI
```

資料來源與研究引擎必須分離，使未來可替換 TWSE、TPEx 或其他合法資料來源，而不影響歷史研究邏輯。

## V1 建議範圍

第一版刻意保持單純：

- 台股個股
- 日 K 歷史資料
- 使用者按需下載
- 本機資料保存與增量更新
- 單一股票研究
- 基本條件組合
- 5／10／20／60 日後統計
- 歷史案例列表
- 基本價格圖表
- 不含 AI
- 不含自動交易
- 不含即時行情平台功能

先驗證「歷史案例搜尋 + 統計」是否真的能讓使用者更快速理解一檔股票，再考慮進一步擴充。
