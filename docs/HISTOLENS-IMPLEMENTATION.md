# 006 HistoLens：實作進度與待確認事項

更新：2026-10-03。依 [006 規格 0.2](products/006_HistoLens.md) 製作。**目前是合成資料開發預覽，不是可供真實股票研究的正式版本。**

後續已完成 [006 全面檢查與優化清單](HISTOLENS-OPTIMIZATION-REVIEW.md)，並依使用者「提交後實作」完成 O01–O13 修正／整合驗證，詳見 [修正紀錄](HISTOLENS-FIXES.md)。目前引擎為 `0.1.1-m0`；案例數值排序、工作保留、載入一致性、三態 AND、背景保存及大量資料保存已補強。真實資料與正式發布仍未完成。

使用者補充方向：先尋找免費資料供應商，或先備妥一組測試資料；可自行持續工作，問題集中留在本文件。

## 目前可操作的範圍

- 工具番目錄新增 `006 HistoLens`，描述明示合成資料開發預覽。暫由工具番宿主管理單一研究視窗；這是開發承載方式，尚未定案正式獨立上架或內建收費方式。
- 使用 `ToolKeeper.UI.AppWindow`／`WindowFrame`，沿用竹紋頂列、預設亮竹子、風格／語言／關於。業務資料與偏好放在 HistoLens 專屬子目錄。
- 按「載入合成測試資料」取得 780 筆可重複產生的日線；`DEMO-006`／`SYNTHETIC` 明示虛構標的。交易日曆只是合成工作日序列，不冒充台灣交易所實際交易日曆。
- 四個透明模板：接近前期低點、連續下跌、量增上漲、收盤突破前高；可調回看期／門檻、事件範圍、截止日、觀察期、採樣政策與上下價格門檻。
- 引擎按明確市場日曆計算，檢查缺值、OHLC、停牌與公司行動；正式統計不把未確認的公司行動覆蓋當作沒有行動。
- 統計與案例使用同一份引擎結果，分期呈現有效 N、漲跌平盤、平均、中位數、分位數、期間極值、收盤最大回撤及門檻觸及。
- 案例可排序、點選查看事件前後原始 OHLC 與收盤路徑；採樣與排除頁保留不可判定／未採用日的原因。
- 可取消研究。改設定後保留舊結果並標示未重跑；舊工作不可覆蓋後來的設定。
- 本機保存完整合成資料快照、研究設定、引擎版本與結果；寫入先落暫存檔再改名，各次保存互不覆寫。v1 格式改用精簡 JSON，保留舊檔讀取，檔案上限 64 MiB；驗證、hash、序列化及 I/O 在背景執行。載入檢查結構、身份、觀察期、計數、校驗碼及資料／結果的快照一致性，完整準備後才替換原工作。

## 操作方式

本次另備有 [隔離啟動檔](../artifacts/histolens-preview/Start-HistoLens.cmd)。在檔案總管雙擊後會開啟這次建置的 006；需已安裝 .NET 10 Desktop Runtime（本機已能完成測試）。預覽使用產物目錄內的 `profile`，預設關閉桌面整理、桌面來源指向空資料夾，且不註冊系統協定，不會覆寫正式工具番偏好。關閉研究視窗後宿主仍遵循既有系統匣生命週期，可由該預覽工具番的系統匣選單退出。

亦可在「開啟研究檔案」選取 [完整合成研究範例](../artifacts/histolens-preview/demo.histolens.json)，直接檢視已完成結果；[原始合成資料快照](../artifacts/histolens-preview/demo.snapshot.json) 則供檢查資料結構，不是介面的研究檔匯入格式。兩者皆非真實股票資料。

1. 建置並開啟新版工具番，點選 `006 HistoLens`，或使用 `toolkeeper://run/006`（僅在新版宿主已註冊協定時）。
2. 按「載入合成測試資料」，選擇模板。預設為連跌至少 3 日，觀察 5／10／20／60 個交易日。
3. 按「執行研究」，查看統計摘要；橫向捲動可看完整統計欄位。
4. 到「歷史案例」選取事件與觀察期，對照原始 OHLC、收盤價格路徑、門檻首次觸及與排除原因。
5. 按「保存這次完整研究」，之後從左側清單或「開啟研究檔案」載入。設定改動後要先重新研究才能保存。

數值輸入採固定格式：日期 `yyyy-MM-dd`，小數點 `.`，觀察期以半形逗號分隔。百分比欄位輸入 `5` 表示 5%；相對成交量輸入 `1.5` 表示 1.5 倍。

一般宿主的資料位置是 `%LOCALAPPDATA%/ToolKeeper/ToolKeeper/HistoLens/`。若以 `--data-directory <隔離目錄>` 啟動，位置為 `<隔離目錄>/toolkeeper-host/HistoLens/`。其中 `ui.json` 是偏好，`research/*.histolens.json` 是保存研究；預覽版只接受合成研究檔案。

## 免費資料來源查證

以下於 2026-10-03 查閱官方說明。**查到免費資料不等於已完成 HistoLens 的歷史品質／公司行動驗收，也不代表所有相鄰 API 都有相同授權。**

| 候選 | 已查到的事實 | 尚待驗證／限制 |
| --- | --- | --- |
| TWSE 證交所 | [政府資料集 11549](https://data.gov.tw/dataset/11549) 列明上市個股日成交的 OHLC、成交股數、成交金額，每日更新、免費，採政府資料開放授權第 1 版；[官方 OpenAPI](https://openapi.twse.com.tw/) 提供對應端點 | 每日開放資料與個股月歷史查詢不能混稱完整歷史 API；請求上限、歷史修訂、普通股識別及公司行動全期間覆蓋待實測 |
| TPEx 櫃買中心 | [政府資料集 11370](https://data.gov.tw/dataset/11370) 列明上櫃行情 OHLC、股數／金額，每日更新、免費，同為政府資料開放授權 | 資料含股票、ETF、ETN，須辨別證券類型；[個股月查詢](https://www.tpex.org.tw/zh-tw/mainboard/trading/info/stock-pricing.html) 的可查年限不自動代表 API 可同方式回補 |
| FinMind | [官方方案頁](https://finmind.github.io/en/Pricing/) 列免費方案為 Non-commercial；300 次／小時，註冊會員 600 次／小時。[API 文件](https://api.finmindtrade.com/docs) 支援 dataset、data_id、日期區間 | 不直接作為商業產品免費供應商；保存、再散布、歷史完整性及必要資料集的實際可用性仍需逐項確認 |

證交所 OpenAPI 列有市場開休市日曆及除權息預告；櫃買也有 [開休市日期表](https://www.tpex.org.tw/zh-tw/announce/market/holiday.html)、[除權息預告資料集](https://data.gov.tw/dataset/11634) 與 [計算結果資料集](https://data.gov.tw/dataset/11633)。這些名稱與頁面不足以證明完整歷史分割、減資、配股、現金股利的覆蓋。公司行動資訊不足時維持阻擋研究，不能以空清單冒充「沒有行動」。

明確適用政府資料開放授權的資料集，依 [官方授權條款](https://data.gov.tw/license) 處理來源標示等要求；正式接入前保存精確資料集、端點與授權版本。這裡記錄來源證據，不代替產品實際用途的專業確認。

建議下一個實作順序：先完成 TWSE 單一上市普通股的歷史資料、交易日曆及公司行動覆蓋驗證，再接按需下载與快照修訂；TPEx 為第二條路徑。這是技術建議，尚未承諾上市／上櫃完整支援。
