# HistoLens：FinMind 唯一下載來源與本機補缺

更新：2026-10-04，0.3.16。依使用者明確決策，歷史行情、股票清單、身分主檔、日曆、公司行動及分析時本益比都只向 FinMind 取得。已移除 TWSE／TPEx 下載器、來源選項、ISIN 網頁查詢、官方日曆回查及內嵌日曆基準；沒有其他網站備援。第一版仍使用未還原原價掃描，在圖表按日期註記事件。

## 操作與補缺

資料管理固定顯示 FinMind，保留上市／上櫃、市場代號及下載起訖日。按「下載缺少資料」才請求行情。更新股票清單、輸入代號及選擇項目不會下载行情。

- 先逐日檢查本機所選來源、市場及證券的已查詢期間、交易日曆及有效日線，將缺口合併成連續區間。
- 已有 2021-01-01..2025-12-31，再選 2016-01-01..2025-12-31，只下載 2016-01-01..2020-12-31 行情；中間缺口也補查，不只看最早／最晚日期。
- 已完整或縮小範圍：零請求、不重寫檔案。這不等同自動刷新歷史修訂；強制修訂更新尚未實作。
- 來源明確的零價／缺價列轉缺值，保留已查詢標記；休市不造 OHLCV，無行情不等於停牌。
- 單次最多十年，起日不得早於 1999-01-05，迄日最晚台灣時間昨日。可查期間不代表任意股票都有完整該段歷史；缺資料不補造。

## 實際端點及欄位

唯一端點為 `https://api.finmindtrade.com/api/v4/data`，直接解析 UTF-8 JSON。這是官網歷史功能使用的公開資料端點，不是自動操作瀏覽器下載 CSV。匿名請求，不帶 Token、Cookie、`device=web`；預設 HttpClient 不跟隨重新導向，不切換來源。欄位說明參考 [FinMind 技術面文件](https://finmind.github.io/tutor/TaiwanMarket/Technical/) 並以實際回應驗證。

| 用途 | dataset | 查詢與主要欄位 |
| --- | --- | --- |
| 日線 | `TaiwanStockPrice` | `data_id/start_date/end_date`；`date/stock_id/open/max/min/close/Trading_Volume/Trading_money/Trading_turnover` |
| 股票清單及來源內身分 | `TaiwanStockInfo` | 全表；`stock_id/stock_name/type/date/industry_category`；依代號最新日期群辨識市場／名稱 |
| 市場交易日 | `TaiwanStockTradingDate` | 獨立日期表；`date`，不能用單股價格日期替代 |
| 除權息 | `TaiwanStockDividendResult` | 單股及缺少區間；實際回應日期作事件日期 |
| 減資 | `TaiwanStockCapitalReductionReferencePrice` | 單股及缺少區間；保留原因及參考價證據 |
| 面額變更 | `TaiwanStockParValueChange` | 範圍表按股票／期間過濾 |
| 分割相關 | `TaiwanStockSplitPrice` | 小型事件表按股票／期間過濾 |
| 最新公布本益比 | `TaiwanStockPER` | `data_id/start_date/end_date`；近 14 天的 `date/stock_id/PER`，取最新資料日 |

`Trading_Volume` 為股，不乘千；`Trading_money` 是成交金額，`Trading_turnover` 是成交筆數。OHLC 的 0、空值及無成交價格不當成有效的 0 元；事件參考價不覆寫原價。成功原始 JSON 與標準化資料分開，保留資料集、實際 URL、UTC 下載時間、筆數、SHA-256。交易日、主檔版本日期與本機取得時間各自保留，不把 hash 當來源官方修訂版本。

歷史下載循序執行、請求間隔 3 秒；來源請求預設 45 秒逾時、8 MiB 上限，不自動重試。清單及本益比各自一次請求；本益比 UI 另有 12 秒上限且不阻擋掃描。這是本程式設定，不是服務承諾額度。必要行情／主檔／日曆失敗保留舊檔；事件失敗記未知覆蓋，HTTP/API 400、401、402、403、429 停止後續事件請求。

## 身分與日曆的確認範圍

新身分使用 `FinMind:市場:代號:版本摘要`，市場、代號、名稱及已知不同版本邊界共同組成，主檔每日更新不會任意改變身分。當前市場或名稱不唯一、範圍跨已知不同市場／名稱版本時拒絕自動串接。只接受四碼且通過来源分類過濾的股票；排除已識別 ETF、ETN、指數、存託及受益證券。

**FinMind 主檔不是完整歷史證券名冊。** 沒有 ISIN、完整掛牌／終止日期或代碼重用證明；不能宣稱所有同碼沿革皆已核實，也不以主檔日期或首筆行情推定掛牌日。清單可能包含來源保留的舊股票，並非保證目前仍交易的公司名冊。資料品質保留身分沿革未確認提醒；已知衝突會保護原檔。

日曆來自 FinMind 獨立交易日表，檢查日期格式、唯一性及查詢期間涵蓋，再核對行情日期。`Calendar.IsVerified` 在本版表示**來源表通過這些檢查**，不代表本次向其他機構獨立核實，也不保證來源未漏臨時休市。診斷與版本明列 `source-validated`。0.3.15 的官方核對屬歷史證據，不再內嵌或於執行期查詢。

完整停復牌目錄、全部公司行動及取消／延後／修訂仍未知。查不到事件不等於沒有；未知覆蓋及跨已知事件不使整次原價相似度掃描停止。真正缺價仍排除受影響窗口；必要基準資料缺失則如實報錯。

## 既有資料相容與保存

新檔使用 `.market-data.json`，舊 `.twse-data.json` 可離線讀取。市場內部鍵 `TWSE/TPEx`、舊來源名稱及來源 URL 僅保留作市場辨識、歷史證據與格式相容，並非下載入口。舊官方行情顯示為本機舊資料，來源不改標 FinMind、不混入新下載。清單新版只記 FinMind URL，舊版兩個 URL 僅供離線格式驗證。

0.3.15 FinMind 快取若使用舊 ISIN 識別，只有其本機保存的 FinMind 主檔證據與新版本身分一致，才保留舊參照繼續補缺；不重新查官方來源。證據缺少或身分改變拒絕合併。失敗、取消、資料衝突不破壞原檔，有效舊價格不默默覆寫；原始證據、hash 及原子保存檢查沿用。保存檔上限仍為 64 MiB。
