# 欢迎使用汗青

打开 Markdown、舒服地阅读，需要修改时按 **Ctrl+E**。

预览模式左侧会自动显示 H1–H6 章节列表，点击章节即可跳转；滚动正文时也会标记当前章节。切换到编辑模式后，左侧编辑原文、右侧实时预览，章节列表会隐藏。拖动两栏中间的分隔线可以调整宽度。

> 文件留在你的电脑里。汗青不需要账户。

## 快速开始

| 操作 | 快捷键 |
| --- | --- |
| 打开文件 | Ctrl+O |
| 新建文件 | Ctrl+N |
| 切换预览／编辑 | Ctrl+E |
| 保存 | Ctrl+S |
| 查找文字 | Ctrl+F |
| 下一个搜索结果 | F3 |
| 关闭当前标签页 | Ctrl+W |
| 全屏阅读 | F11 |

左侧工具栏可新建文件或窗口、另存为，以及打开最近使用的文件。字体与亮色、深色、竹子（亮色）、竹子（深色）主题也在工具栏；语言和窗口尺寸可从「更多」调整。点击工具栏最上方的按钮，可展开功能名称、说明与快捷键；再点一次收起。鼠标移入或移开都不会自动改变状态。

「更多」中的「章节大纲」可选择显示的 H1–H6 级别，同时应用到 Markdown 预览与导出 PDF。「关闭时保留当前打开文件」默认关闭；启用后，下次启动会重新打开先前的文件，未保存内容仍会提示。

字体设置分成「UI 界面」「正文预览」「正文编辑器」，各自选择字体与字号，调整后会立即应用并记住设置。

切换到编辑模式后，文件上方会显示编辑工具栏。可直接选择编辑器字体（自动等宽、传统文字或电脑已安装的字体），并输入 8–72 的字号或使用 **−／+** 调整。这些设置只影响编辑时的显示，会记住偏好，不会把字体或字号写进 Markdown。切回预览或关闭所有文件后，这列会隐藏。

新安装默认使用「竹子（亮色）」，以竹子界面搭配宣纸底色；亮色与深色纸面都呈现清晰、疏松的纤维纹路。已有的主题选择会继续沿用。可从「更多 → 常规 → 主题」选择「竹子（深色）」，或切换竹子（亮色）、亮色、深色及跟随系统。侧栏主题按钮依亮色 → 深色 → 竹子（亮色）→ 竹子（深色）循环。

竹子（亮色）及竹子（深色）主题下，界面与预览字体选「自动」都会搭配「传统文字」；繁体中文优先使用电脑上已安装的标楷体。任一组字体设置也可直接选择「传统文字」。已明确指定的字体不会被主题覆盖，编辑器默认维持等宽字体。

默认界面字号为 15，正文预览与编辑器字号皆为 16，工具栏保持展开。自动保存默认启用：已有保存位置的文件停止修改 3 秒后会保存；新文件第一次仍需使用 **Ctrl+S** 选择位置。

## 导出 PDF

点击左侧工具栏「保存」下方的「导出 PDF」，汗青会先保存 Markdown，再于同一文件夹生成附有本地时间的 PDF，例如 `笔记.md` → `笔记_20260922_153012.pdf`（`yyyyMMdd_HHmmss`）。

新文件会先询问 Markdown 的保存位置；若取消或保存失败，就不会导出。同名 PDF 已存在时会先确认是否覆盖。PDF 采用白底 A4 版面及当前的正文预览字体与字号，包含完整内容与本地图片。

## 代码

```csharp
var message = "Read. Edit. Save.";
Console.WriteLine(message);
```

代码右上角可直接复制。也能选取一般文字，使用 **Ctrl+Shift+C** 复制 Markdown。

## 编辑小技巧

1. 使用编辑工具栏的段落菜单切换正文或 **H1–H6** 标题。
2. 选取文字后，可点粗体、斜体、删除线、行内代码或链接；粗体与斜体也可使用 **Ctrl+B**、**Ctrl+I**。这些操作会插入标准 Markdown 语法，可按 **Ctrl+Z** 恢复。
3. 选取文字后贴上网址，会建立 Markdown 链接。
4. 在编辑模式中贴上图片，会保存到文件旁的 `images` 文件夹。
5. 在预览中按右键选择「在此编辑」，会跳至对应段落。

只读文件保留保护，无法通过格式按钮修改内容。

搜索浮动窗口在编辑模式中可展开替换。**全部替换前会先确认**。
