# Páginas tranquilas

> Convierte los pequeños momentos en palabras que merezcan conservarse.

La luz de la mañana cae sobre el escritorio. Abre una página y anota algo que quieras recordar de hoy.
No hace falta terminar un ensayo largo. Empieza con un encabezado y unas líneas, y deja espacio para que tus ideas crezcan.

## Tres pequeñas cosas para hoy

- [x] Leer un capítulo de un libro favorito
- [x] Escribir notas de un paseo junto al río
- [ ] Reservar un poco de tiempo para planear el fin de semana

## Un lugar para cada idea

Usa **encabezados** para separar temas, *cursiva* para dar un poco de énfasis y listas para ordenar los pensamientos.
Unas notas sencillas bastan si te ayudan a recordar cómo se sintió un momento.

### Un ritmo semanal de escritura

| Cuándo | Un pequeño plan | Qué conservar |
| --- | --- | --- |
| Lunes | Leer durante quince minutos | Una frase favorita |
| Miércoles | Pasear junto al río | Tres observaciones |
| Fin de semana | Volver a las notas de la semana | El inicio de una página nueva |
