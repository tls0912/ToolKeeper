# 歡迎使用 MarkPad

開啟 Markdown、舒服地閱讀，需要修改時按 **Ctrl+E**。

> 文件留在你的電腦裡。MarkPad 不需要帳號。

## 快速開始

| 操作 | 快捷鍵 |
| --- | --- |
| 開啟文件 | Ctrl+O |
| 新增文件 | Ctrl+N |
| 切換預覽／編輯 | Ctrl+E |
| 儲存 | Ctrl+S |
| 尋找文字 | Ctrl+F |
| 下一個搜尋結果 | F3 |
| 關閉目前分頁 | Ctrl+W |
| 全螢幕閱讀 | F11 |

在左側工具列調整字型、亮暗主題與語言。點擊工具列最上方的按鈕，可展開功能名稱、說明與快捷鍵；再點一次收合。滑鼠移入或移開都不會自動改變狀態。

字型設定分成「UI 介面」「內文預覽」「內文編輯器」，各自選擇字型與字級，調整後會立即套用並記住設定。

預設三組字級皆為 16，工具列保持展開。自動儲存預設開啟：已有儲存位置的文件停止修改 3 秒後會儲存；新文件第一次仍需使用 **Ctrl+S** 選擇位置。

## 匯出 PDF

點擊左側工具列「儲存」下方的「匯出 PDF」，MarkPad 會先儲存 Markdown，再於同一資料夾產生附有本機時間的 PDF，例如 `筆記.md` → `筆記_20260922_153012.pdf`（`yyyyMMdd_HHmmss`）。

新文件會先詢問 Markdown 的儲存位置；若取消或儲存失敗，就不會匯出。同名 PDF 已存在時會先確認是否覆寫。PDF 採用白底 A4 版面及目前的內文預覽字型與字級，包含完整內容與本機圖片。

## 待辦清單

- [ ] 點擊此方框，觀察分頁的未儲存標記
- [ ] 按 Ctrl+S 儲存變更

## 程式碼

```csharp
var message = "Read. Edit. Save.";
Console.WriteLine(message);
```

程式碼右上角可直接複製。也能選取一般文字，使用 **Ctrl+Shift+C** 複製 Markdown。

## 編輯小技巧

1. 選取文字後按 **Ctrl+B** 或 **Ctrl+I**。
2. 選取文字後貼上網址，會建立 Markdown 連結。
3. 在編輯模式中貼上圖片，會儲存到文件旁的 `images` 資料夾。
4. 在預覽中按右鍵選擇「在此編輯」，會跳至對應段落。

搜尋浮窗在編輯模式中可展開取代。**全部取代前會先確認**。
