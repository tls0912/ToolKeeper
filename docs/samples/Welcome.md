# 歡迎使用汗青

開啟 Markdown、舒服地閱讀，需要修改時按 **Ctrl+E**。

預覽模式左側會自動顯示 H1–H6 章節列表，點選章節即可跳轉；捲動內文時也會標示目前章節。切換到編輯模式後，左側編輯原稿、右側即時預覽，章節列表會隱藏。拖曳兩欄中間的分隔線可以調整寬度。

> 文件留在你的電腦裡。汗青不需要帳號。

## 快速開始

| 操作 | 快捷鍵 |
| --- | --- |
| 開啟文件 | Ctrl+O |
| 新增文件 | Ctrl+N |
| 切換預覽／編輯 | Ctrl+E |
| 儲存 | Ctrl+S |
| 尋找文字 | Ctrl+F |
| 下一個搜尋結果 | F3 |
| 關閉目前分頁 | Ctrl+W |
| 全螢幕閱讀 | F11 |

左側工具列可新增文件或視窗、另存新檔，以及開啟最近使用的文件。字型與亮色、深色、竹子（亮色）、竹子（深色）主題也在工具列；語言和視窗尺寸可從「更多」調整。點擊工具列最上方的按鈕，可展開功能名稱、說明與快捷鍵；再點一次收合。滑鼠移入或移開都不會自動改變狀態。

「更多」中的「章節大綱」可選擇顯示的 H1–H6 層級，同時套用到 Markdown 預覽與匯出 PDF。「關閉時保留當前開啟檔案」預設關閉；啟用後，下次啟動會重新開啟先前的文件，未儲存內容仍會提示。

字型設定分成「UI 介面」「內文預覽」「內文編輯器」，各自選擇字型與字級，調整後會立即套用並記住設定。

切換到編輯模式後，文件上方會顯示編輯工具列。可直接選擇編輯器字型（自動等寬、傳統文字或電腦已安裝的字型），並輸入 8–72 的字級或使用 **−／+** 調整。這些設定只影響編輯時的顯示，會記住偏好，不會把字型或字級寫進 Markdown。切回預覽或關閉所有文件後，這列會隱藏。

新安裝預設使用「竹子（亮色）」，以竹子介面搭配宣紙底色；亮色與深色紙面都呈現清晰、疏鬆的纖維紋路。已有的主題選擇會繼續沿用。可從「更多 → 一般 → 主題」選擇「竹子（深色）」，或切換竹子（亮色）、亮色、深色及跟隨系統。側欄主題按鈕依亮色 → 深色 → 竹子（亮色）→ 竹子（深色）循環。

竹子（亮色）及竹子（深色）主題下，介面與預覽字型選「自動」都會搭配「傳統文字」；繁體中文優先使用電腦上已安裝的標楷體。任一組字型設定也可直接選擇「傳統文字」。已明確指定的字型不會被主題覆蓋，編輯器預設維持等寬字型。

預設介面字級為 15，內文預覽與編輯器字級皆為 16，工具列保持展開。自動儲存預設開啟：已有儲存位置的文件停止修改 3 秒後會儲存；新文件第一次仍需使用 **Ctrl+S** 選擇位置。

## 匯出 PDF

點擊左側工具列「儲存」下方的「匯出 PDF」，汗青會先儲存 Markdown，再於同一資料夾產生附有本機時間的 PDF，例如 `筆記.md` → `筆記_20260922_153012.pdf`（`yyyyMMdd_HHmmss`）。

新文件會先詢問 Markdown 的儲存位置；若取消或儲存失敗，就不會匯出。同名 PDF 已存在時會先確認是否覆寫。PDF 採用白底 A4 版面及目前的內文預覽字型與字級，包含完整內容與本機圖片。

## 程式碼

```csharp
var message = "Read. Edit. Save.";
Console.WriteLine(message);
```

程式碼右上角可直接複製。也能選取一般文字，使用 **Ctrl+Shift+C** 複製 Markdown。

## 編輯小技巧

1. 使用編輯工具列的段落選單切換內文或 **H1–H6** 標題。
2. 選取文字後，可點粗體、斜體、刪除線、行內程式碼或連結；粗體與斜體也可使用 **Ctrl+B**、**Ctrl+I**。這些操作會插入標準 Markdown 語法，可按 **Ctrl+Z** 復原。
3. 選取文字後貼上網址，會建立 Markdown 連結。
4. 在編輯模式中貼上圖片，會儲存到文件旁的 `images` 資料夾。
5. 在預覽中按右鍵選擇「在此編輯」，會跳至對應段落。

唯讀文件保留保護，無法透過格式按鈕修改內容。

搜尋浮窗在編輯模式中可展開取代。**全部取代前會先確認**。
