# 汗青へようこそ

Markdown を開いて、ゆったり読む。編集したいときは **Ctrl+E** を押します。

プレビューでは、左側に H1–H6 の見出し一覧が表示されます。見出しをクリックするとその位置へ移動し、本文のスクロールに合わせて現在の章が示されます。編集モードでは左側に原稿、右側にプレビューが表示され、見出し一覧は隠れます。中央の区切りをドラッグすると幅を調整できます。

> 文書はお使いのパソコンに保存されます。汗青にアカウントは不要です。

## クイックスタート

| 操作 | ショートカット |
| --- | --- |
| 文書を開く | Ctrl+O |
| 新しい文書 | Ctrl+N |
| プレビュー／編集を切り替える | Ctrl+E |
| 保存 | Ctrl+S |
| 文字列を検索 | Ctrl+F |
| 次の検索結果 | F3 |
| 現在のタブを閉じる | Ctrl+W |
| 全画面で読む | F11 |

左側のツールバーから、文書やウィンドウの新規作成、名前を付けて保存、最近使った文書の表示ができます。フォントやテーマもここで選べます。言語とウィンドウサイズは「その他」で調整します。ツールバー最上部のボタンを押すと、機能名、説明、ショートカットが展開され、もう一度押すと折りたたまれます。マウスを重ねたり離したりしても状態は変わりません。

「その他」の章のアウトライン設定では、表示する H1–H6 の階層を選びます。この設定は Markdown のプレビューと PDF 出力の両方に適用されます。終了時に開いているファイルを保持する設定は、初期状態では無効です。有効にすると次回起動時に文書を開き直します。未保存の変更は引き続き確認されます。

フォント設定は、画面、本文プレビュー、エディターの三つに分かれています。それぞれのフォントとサイズを選べ、変更はすぐに反映され、記憶されます。

編集モードでは文書の上に編集ツールバーが表示されます。エディターのフォントを自動等幅、伝統的な文字、インストール済みのフォントから選び、8–72 のサイズを入力するか **−／+** で調整できます。設定は記憶されますが、Markdown には書き込まれません。プレビューに戻るか、すべての文書を閉じると、このツールバーは隠れます。

新規インストール時のテーマは「竹（ライト）」です。竹の画面に紙の背景を組み合わせ、明るい紙面と暗い紙面の両方に繊維の模様を表示します。既存のテーマ設定は引き継がれます。「その他 → 一般 → テーマ」で選択でき、サイドバーのボタンはライト、ダーク、竹（ライト）、竹（ダーク）の順に切り替わります。

竹のテーマでは、画面とプレビューの自動フォントに伝統的な文字を使用します。繁体字中国語では、インストール済みの標楷体が優先されます。伝統的な文字は直接選ぶこともできます。明示的に選んだフォントは維持され、エディターは等幅フォントが初期設定です。

初期の文字サイズは画面が 15、本文プレビューとエディターが 16 です。ツールバーは展開された状態で始まります。自動保存は初期状態で有効です。保存先がある文書は、編集が止まってから 3 秒後に保存されます。新しい文書は、最初に **Ctrl+S** で保存先を選びます。

## PDF 出力

左側ツールバーの「保存」の下にある「PDF 出力」を押します。汗青は先に Markdown を保存し、同じフォルダーにローカル日時を付けた PDF を作成します。例：`メモ.md` → `メモ_20260922_153012.pdf`（`yyyyMMdd_HHmmss`）。

新しい文書では、先に Markdown の保存先を尋ねます。キャンセルした場合や保存に失敗した場合、PDF は出力されません。同名の PDF がある場合は上書きを確認します。PDF は白い A4 用紙で、現在の本文プレビューのフォントとサイズを使い、全文とローカル画像を含みます。

## コード

```csharp
var message = "Read. Edit. Save.";
Console.WriteLine(message);
```

コードの右上のボタンでコピーできます。通常の文字列を選択して **Ctrl+Shift+C** を押すと、Markdown としてコピーできます。

## 編集のヒント

1. 編集ツールバーの段落メニューで、本文や **H1–H6** の見出しを選びます。
2. 文字列を選択して、太字、斜体、取り消し線、インラインコード、リンクを適用できます。太字と斜体は **Ctrl+B**、**Ctrl+I** でも操作できます。標準の Markdown 構文が挿入され、**Ctrl+Z** で元に戻せます。
3. 選択した文字列に URL を貼り付けると、Markdown リンクになります。
4. 編集モードで画像を貼り付けると、文書の隣の `images` フォルダーに保存されます。
5. プレビューで右クリックして「ここで編集」を選ぶと、対応する段落へ移動します。

読み取り専用の文書は保護され、書式ボタンから内容を変更することはできません。

編集モードでは、検索パネルを展開して置換できます。**すべて置換する前には確認が表示されます。**
