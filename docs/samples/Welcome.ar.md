# مرحبًا بك في 汗青

افتح ملف Markdown واقرأ براحة، واضغط **Ctrl+E** حين تحتاج إلى التحرير.

في وضع المعاينة، تظهر عناوين H1–H6 على الجانب الأيسر. انقر على عنوان للانتقال إليه؛ ويُبرز التمرير أيضًا القسم الحالي. في وضع التحرير، يظهر النص المصدري على اليسار والمعاينة الفورية على اليمين، وتُخفى قائمة العناوين. اسحب الفاصل لضبط عرض العمودين.

> تبقى مستنداتك على جهازك. لا يتطلب 汗青 حسابًا.

## البدء السريع

| الإجراء | الاختصار |
| --- | --- |
| فتح مستند | Ctrl+O |
| مستند جديد | Ctrl+N |
| التبديل بين المعاينة والتحرير | Ctrl+E |
| حفظ | Ctrl+S |
| البحث عن نص | Ctrl+F |
| نتيجة البحث التالية | F3 |
| إغلاق علامة التبويب الحالية | Ctrl+W |
| القراءة بملء الشاشة | F11 |

يتيح لك شريط الأدوات الأيسر إنشاء مستندات أو نوافذ، وحفظ نسخة، وفتح المستندات الحديثة. ويوفّر أيضًا أدوات للتحكم في الخطوط والسمات؛ أما اللغة وحجم النافذة فتجدهما ضمن «المزيد». انقر على الزر أعلى الشريط لتوسيع أسماء الأزرار وأوصافها واختصاراتها، وانقر مجددًا لطيه. لا تتغير حالة الشريط عند تحريك المؤشر فوقه.

يحدد إعداد «مخطط الفصول» ضمن «المزيد» مستويات H1–H6 المستخدمة في معاينة Markdown وتصدير PDF معًا. يكون خيار الاحتفاظ بالملفات المفتوحة عند الخروج معطّلًا افتراضيًا. فعّله لإعادة فتح تلك المستندات عند التشغيل التالي؛ وستظل تظهر مطالبة بشأن التغييرات غير المحفوظة.

إعدادات الخطوط منفصلة للواجهة ومعاينة القراءة والمحرر. لكل منها خط وحجم مستقلان؛ وتُطبّق التغييرات فورًا ويُحتفظ بها.

يعرض وضع التحرير شريطًا للتنسيق فوق المستند. اختر خطًا للمحرر (أحادي المسافة تلقائيًا، أو خطًا تقليديًا، أو أحد الخطوط المثبتة)، وأدخل حجمًا من 8 إلى 72، أو استخدم **− / +**. تؤثر هذه التفضيلات في عرض المحرر، ويُحتفظ بها دون كتابتها في ملف Markdown. يختفي الشريط في وضع المعاينة أو عند إغلاق جميع المستندات.

تستخدم التثبيتات الجديدة سمة «الخيزران (فاتح)»، التي تجمع واجهة من الخيزران وخلفية ورقية. تظهر ألياف الورق في سمتَي الخيزران. يُحتفظ بتفضيل السمة الموجود مسبقًا. اختر سمة من «المزيد ← عام ← السمة»؛ ويتنقل زر الشريط الجانبي بين «فاتح» و«داكن» و«الخيزران (فاتح)» و«الخيزران (داكن)».

في سمتَي الخيزران، تستخدم الخطوط التلقائية للواجهة والمعاينة خطًا تقليديًا. للصينية التقليدية، يُفضَّل خط BiauKai إذا كان مثبتًا. ويمكنك أيضًا اختيار الخط التقليدي مباشرةً. يُحتفظ بالخطوط التي تختارها صراحةً، ويستخدم المحرر خطًا أحادي المسافة افتراضيًا.

حجم خط الواجهة الافتراضي 15، وحجم خط المعاينة والمحرر 16. يبدأ شريط الأدوات موسّعًا. الحفظ التلقائي مفعّل افتراضيًا: يُحفظ المستند الذي له مسار حفظ بعد ثلاث ثوانٍ من توقف التحرير. أما المستند الجديد فيحتاج أولًا إلى **Ctrl+S** لاختيار مكان حفظه.

## تصدير PDF

انقر على «تصدير PDF» أسفل «حفظ» في شريط الأدوات الأيسر. يحفظ 汗青 ملف Markdown أولًا، ثم ينشئ ملف PDF في المجلد نفسه مع طابع زمني محلي، مثل `Notes.md` ← `Notes_20260922_153012.pdf` (`yyyyMMdd_HHmmss`).

يطلب المستند الجديد أولًا اختيار مكان لحفظ Markdown. يؤدي إلغاء الحفظ أو فشله إلى إيقاف التصدير. تظهر مطالبة قبل الكتابة فوق ملف PDF موجود. يستخدم PDF صفحات A4 بيضاء والخط والحجم الحاليين للمعاينة، ويشمل المحتوى الكامل والصور المحلية.

## قوائم المهام

هذا مثال لقائمة مهام في Markdown. عندما لا يكون أي مستند مفتوحًا، تكون هذه المقدمة للقراءة فقط. افتح مستندًا أو أنشئ واحدًا أولًا، ثم جرّب تحديد العناصر وحفظها في مستندك.

- [x] فتح مستند Markdown
- [ ] تحديد عنصر في مستندك وملاحظة علامة التغييرات غير المحفوظة في علامة التبويب
- [ ] الضغط على Ctrl+S لحفظ التغييرات

## الشيفرة

```csharp
var message = "Read. Edit. Save.";
Console.WriteLine(message);
```

استخدم الزر أعلى يمين كتلة الشيفرة لنسخها. ويمكنك أيضًا تحديد نص عادي والضغط على **Ctrl+Shift+C** لنسخ Markdown.

## نصائح للتحرير

1. استخدم قائمة الفقرة في شريط التنسيق للنص العادي أو عناوين **H1–H6**.
2. حدد نصًا لتطبيق الغامق أو المائل أو النص الذي يتوسطه خط أو الشيفرة المضمنة أو رابط. يطبّق **Ctrl+B** و**Ctrl+I** الغامق والمائل أيضًا. تُدرج هذه الإجراءات صيغة Markdown القياسية، ويمكن التراجع عنها باستخدام **Ctrl+Z**.
3. الصق عنوان URL فوق النص المحدد لإنشاء رابط Markdown.
4. الصق صورة في وضع التحرير لحفظها في مجلد `images` بجانب المستند.
5. انقر بزر الفأرة الأيمن في المعاينة واختر «التحرير هنا» للانتقال إلى الفقرة المقابلة.

تظل المستندات المخصصة للقراءة فقط محمية من التغييرات عبر أزرار التنسيق.

في وضع التحرير، وسّع لوحة البحث لاستبدال النص. **يطلب «استبدال الكل» التأكيد أولًا.**
