# 竹间札记

> 把日常的片刻，写成值得保存的文字。

清晨，窗边的光落在桌面上。打开一份笔记，先写下今天最想记得的一件事。
不急着完成长篇文章，从一个标题、一段文字开始，慢慢整理自己的想法。

## 今天的三件小事

- [x] 读完一章喜欢的书
- [x] 记下一段散步时想到的文字
- [ ] 留一点时间，整理周末的计划

## 让想法有自己的位置

用 **标题** 分开主题，以 *斜体* 留下语气，用清单把想法排整齐。
文字可以很简单，只要下次回来时，还能找得到当初的心情。

### 一周的写作节奏

| 时间 | 小小的安排 | 留下的记录 |
| --- | --- | --- |
| 周一 | 读书十五分钟 | 一句喜欢的话 |
| 周三 | 沿着河岸散步 | 三个新观察 |
| 周末 | 回看这周笔记 | 下一篇的开头 |

## 收集生活的片段

在笔记里保留一段简短的代码，也能让做过的事情更容易重现。

```json
{
  "notebook": "竹间札记",
  "habit": "每天留下一段文字"
}
```

### 下次续写

1. 选一个值得多看一眼的细节。
2. 写下它为什么让自己停留。
3. 把草稿读一遍，留住最清楚的文字。

#### 从一句话开始

不必一次写完，明天再接着写。

##### 留给自己的提醒

好的笔记，是日后还愿意再读的文字。

###### 今日收笔

把文件存好，让今天的想法有一个安稳的位置。
