# 汗青에 오신 것을 환영합니다

Markdown 문서를 열어 편안하게 읽고, 편집이 필요할 때 **Ctrl+E**를 누르세요.

미리 보기 모드에서는 왼쪽에 H1–H6 제목 목록이 표시됩니다. 제목을 클릭하면 해당 위치로 이동하며, 스크롤할 때도 현재 읽는 부분이 강조됩니다. 편집 모드에서는 왼쪽에 원문, 오른쪽에 실시간 미리 보기가 표시되고 제목 목록은 숨겨집니다. 구분선을 드래그해 각 영역의 너비를 조절할 수 있습니다.

> 문서는 내 컴퓨터에 그대로 남습니다. 汗青은 계정이 필요하지 않습니다.

## 빠르게 시작하기

| 작업 | 단축키 |
| --- | --- |
| 문서 열기 | Ctrl+O |
| 새 문서 | Ctrl+N |
| 미리 보기 / 편집 모드 전환 | Ctrl+E |
| 저장 | Ctrl+S |
| 텍스트 찾기 | Ctrl+F |
| 다음 검색 결과 | F3 |
| 현재 탭 닫기 | Ctrl+W |
| 전체 화면으로 읽기 | F11 |

왼쪽 도구 모음에서 새 문서나 창을 만들고, 사본을 저장하거나 최근 문서를 열 수 있습니다. 글꼴과 테마도 조절할 수 있으며, 언어와 창 크기는 더 보기에 있습니다. 도구 모음 맨 위의 버튼을 클릭하면 이름, 설명, 단축키가 펼쳐지고 다시 클릭하면 접힙니다. 마우스 포인터를 올리는 것만으로는 도구 모음 상태가 바뀌지 않습니다.

더 보기의 목차 설정에서는 Markdown 미리 보기와 PDF 내보내기에 사용할 H1–H6 단계를 선택합니다. 종료할 때 열린 파일을 기억하는 옵션은 기본적으로 꺼져 있습니다. 켜면 다음 실행 시 해당 문서를 다시 열며, 저장하지 않은 변경 내용이 있으면 여전히 저장 여부를 묻습니다.

인터페이스, 읽기 미리 보기, 편집기의 글꼴은 각각 설정합니다. 각 영역에 별도의 글꼴과 크기가 있으며, 변경하면 바로 적용되고 다음에도 유지됩니다.

편집 모드에서는 문서 위에 서식 도구 모음이 표시됩니다. 편집기 글꼴은 자동 고정폭, 전통 서체, 설치된 글꼴 중에서 선택할 수 있습니다. 크기는 8부터 72까지 입력하거나 **− / +**로 조절하세요. 이 설정은 편집기 화면에만 적용되며, Markdown에 기록되지 않고 별도로 저장됩니다. 미리 보기 모드로 전환하거나 모든 문서를 닫으면 도구 모음이 숨겨집니다.

새로 설치하면 대나무 인터페이스와 종이 배경을 조합한 대나무(밝음) 테마를 사용합니다. 두 대나무 테마 모두 종이의 섬유 질감이 보입니다. 기존에 선택한 테마는 유지됩니다. 더 보기 → 일반 → 테마에서 선택할 수 있으며, 사이드바의 테마 버튼은 밝음, 어두움, 대나무(밝음), 대나무(어두움) 순서로 전환합니다.

대나무 테마에서는 인터페이스와 미리 보기 글꼴을 자동으로 설정하면 전통 서체를 사용합니다. 중국어 번체는 설치된 표해체(BiauKai) 글꼴을 우선 사용합니다. 전통 서체를 직접 선택할 수도 있습니다. 직접 선택한 글꼴은 유지되며, 편집기의 기본 글꼴은 고정폭입니다.

인터페이스의 기본 글자 크기는 15이며, 미리 보기와 편집기는 16입니다. 도구 모음은 처음에 펼쳐진 상태입니다. 자동 저장은 기본적으로 켜져 있어 저장 위치가 정해진 문서는 입력을 멈춘 뒤 3초 후에 저장됩니다. 새 문서는 **Ctrl+S**로 첫 저장 위치를 지정해야 합니다.

## PDF 내보내기

왼쪽 도구 모음에서 저장 아래에 있는 PDF 내보내기를 클릭하세요. 汗青은 먼저 Markdown을 저장한 뒤 같은 폴더에 현지 날짜와 시간이 붙은 PDF를 만듭니다. 예를 들어 `Notes.md` → `Notes_20260922_153012.pdf`와 같은 형식입니다(`yyyyMMdd_HHmmss`).

새 문서라면 먼저 Markdown을 저장할 위치를 묻습니다. 저장을 취소하거나 저장에 실패하면 내보내기가 중단됩니다. 기존 PDF를 덮어쓸 때는 먼저 확인을 요청합니다. PDF는 흰색 A4 용지에 현재 미리 보기 글꼴과 크기를 사용하며, 전체 내용과 로컬 이미지를 포함합니다.

```csharp
var message = "Read. Edit. Save.";

```

코드 블록 오른쪽 위의 버튼을 누르면 코드를 복사할 수 있습니다. 일반 텍스트를 선택하고 **Ctrl+Shift+C**를 눌러 Markdown으로 복사할 수도 있습니다.

## 편집 팁

1. 서식 도구 모음의 문단 메뉴에서 본문 또는 **H1–H6** 제목을 선택하세요.
2. 텍스트를 선택해 굵게, 기울임꼴, 취소선, 인라인 코드 또는 링크를 적용하세요. **Ctrl+B**와 **Ctrl+I**로도 굵게와 기울임꼴을 적용할 수 있습니다. 표준 Markdown이 삽입되며 **Ctrl+Z**로 실행 취소할 수 있습니다.
3. 선택한 텍스트 위에 URL을 붙여 넣으면 Markdown 링크가 만들어집니다.
4. 편집 모드에서 이미지를 붙여 넣으면 문서 옆의 `images` 폴더에 저장됩니다.
5. 미리 보기에서 마우스 오른쪽 버튼을 누르고 여기서 편집을 선택하면 해당 문단으로 이동합니다.

읽기 전용 문서는 서식 버튼을 사용해도 변경되지 않도록 보호됩니다.

편집 모드에서 검색 패널을 펼치면 텍스트를 바꿀 수 있습니다. **모두 바꾸기는 먼저 확인을 요청합니다.**
