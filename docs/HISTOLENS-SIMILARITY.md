# 006：近期走勢與歷史相似度掃描

更新：2026-10-04。對應產品規格0.3.8；本輪追加原價掃描與事件註記，事件／不比價／覆蓋未知不再全域阻擋掃描。既有選股自動載入、掃描日期元件、指標記憶、資料管理頁面、日級資料補齊與走勢疊圖維持。這是開發預覽的功能與計算紀錄，資料來源實測及限制見[官方歷史資料驗證](HISTOLENS-DATA-VERIFICATION.md)。

## 使用者已確認的核心

以今日往回選定一段期間，掃描歷史上哪裡相像。每項指標有自己的相似度，最後有總相似度；執行前設定「最低總相似度（含等於）」及「歷史掃描起訖」。主要用途是數值比較；依後續要求，進階條件研究入口已隱藏。

## 操作

1. 上方可切換「放大鏡」與「資料管理」。目前個人版可在資料管理選擇上市（TWSE）或上櫃（TPEx），輸入普通股代碼與下載起迄日，再按「下載官方資料」。系統先按日比對，完整時直接使用本機資料，缺漏才補齊；同市場、同一證券身分合併保存一份。清單列出股票、市場、保存範圍、實際行情首末日及日線筆數；內建合成測試資料也列在同一份清單，共用「在放大鏡開啟」，不另設合成資料載入按鈕。在放大鏡的股票選單選取後即自動載入，不必再按「載入所選股票」。
2. 設定「近期區間」，預設 20 個交易日，可填 5–250。「比對指標」直接顯示，十項指標都可個別勾選；至少一項才能掃描。勾選、全選及恢復原五項會自動記憶，重新開啟後恢復；首次使用預設原五項。
3. 用日期元件選擇「歷史掃描起日／迄日」，並設定「總相似度至少」，門檻預設 60，可填 0–100。無效、空白或反向日期不執行掃描，保留原結果。
4. 在股票選單正下方按「尋找相似區間」，執行中可按旁邊的「取消」。列表顯示歷史日期、總相似度及本次勾選指標的分數，數值靠右；選取一列，下方完整歷史圖會定位該區間，疊上近期走勢，並帶出區間結束後的歷史行情。可縮放、左右瀏覽或回到全部歷史。向下捲動可看近期與歷史的實值及「相似度怎麼算」，內容直接顯示，不需要點擊展開。可按欄位排序，排序使用未四捨五入數字。
5. 資料詳情、比對指標、指標明細與公式均使用固定區塊，內容較長時捲動查看。「資料品質」「資料來源／方法」「原始日線行情」保留可見分頁。「條件研究（進階）」入口隱藏。

交易日、指標集合、等權、預設值及下列公式是本輪工程選擇，不是使用者逐項指定，也不代表已驗證的投資模型。

## 資料管理

- 按「更新上市櫃股票清單」取得並保存目前公司主檔；下次開啟直接讀本機，不自動連線更新。輸入完整代號會定位旁邊下拉項目，選下拉項目會回填代號及市場；同碼優先目前市場，只有另一市場唯一符合時才同步切換。未完成或未知代號保留原輸入，沒有清單仍可手動下載。
- 清單更新時間、上市／上櫃筆數會顯示於更新按鈕下方；更新失敗保留舊清單。清單更新及選股不下載價格，歷史行情仍需按「下載官方資料」。來源與當次實測見 [清單來源](HISTOLENS-STOCK-CATALOG-SOURCES.md)。
- 下載起迄日使用日期元件，可開啟日曆選日期。日期留空、無效或起日大於迄日會先擋下，不沿用先前日期發送下載，也不清除現有研究。
- 「重新整理清單」讀取本機保存內容，不發送行情下載請求。
- 內建合成測試資料清楚標示為非真實行情，不計入已保存股票數、不建立 TWSE 行情檔，也不提供刪除。
- 自動載入只回應使用者選股；刷新清單與下載後同步選項不重複載入。切換選股時較舊的載入不覆蓋新選擇；載入失敗保留原資料與結果並恢復原選項。
- 保存起迄日是資料涵蓋的外圍日期，不表示區間內沒有缺漏。行情首末日只計有有效收盤價的交易日；日線筆數包括已保存的未成交狀態列。
- 選取一支股票按「刪除所選資料…」，確認框顯示股票及保存日期。只移除該股票的現用行情資料，其他股票、已保存的研究快照與舊版備份保留。
- 刪除目前已載入的行情，會清空放大鏡中的資料、相似結果與圖；刪除其他股票則保留目前工作。取消或刪除失敗保留原資料。
- 頁面切換保留選取結果與圖表位置。下載、開啟或刪除執行中停用重複操作；「取消」隨頁面移至放大鏡股票選單下方或資料管理下載區。
- 刪除與下載使用同一個資料鎖；不接受庫存以外路徑、巢狀備份、研究檔或符號連結。損毀的現用行情檔會顯示錯誤，不會被當成空清單繼續修改。

## 兩個區間分開

- **近期基準**：截至資料中最近的已完成市場交易日、且不晚於台灣今日，向前取 N 個交易日，含末日。N 筆收盤價有 N−1 次相鄰日變動。休市不增加交易日，停牌／缺價不偷偷跳過。
- **歷史掃描區間**：整個歷史片段都必須落在設定的起訖內（含邊界），長度同為 N 個市場交易日，而且片段末日必須早於近期基準起日。
- **資料下載範圍**：決定本機有什麼資料；修改掃描區間不會觸發下载。需要更久以前的歷史時，先擴大下載範圍。
- 最新資料仍以快照標記的已完成截止為準；不把舊資料或休市前行情寫成今日即時行情。既有 TWSE 下載流程保守限制已完成日期，仍沿用其來源規則。
- 最新基準缺價或停牌時不能捏造有效比較，也不偷偷换成更早的基準。2026-10-04 政策：跨公司行動或不比價邊界改為原價掃描與事件提醒，不全域阻擋。

## 完整歷史圖與所選區間疊圖

- 載入股票資料後，圖表即提供整份已載入、截至快照截止日的歷史走勢；不以歷史掃描起訖或單一相似片段裁掉其餘資料，也不會自動下載缺少的更遠歷史。
- 點選相似結果後，自動定位該片段並保留前後脈絡：前方約半個比對窗口，後方至少以 `max(60, 3×N)` 個交易日為顯示目標，實際限於已有資料。相似片段有底色及結束邊界，右方是該時點之後實際發生的歷史走勢。
- 圖表提供「完整歷史」「定位相似區間」及縮放控制，下方水平捲軸可瀏覽整個時間範圍。查看全部歷史或移動視窗時，選取結果與近期疊線仍保留。
- 歷史走勢為青綠色細線（1.6 DIP）；近期走勢為橘色粗線（3.4 DIP），在歷史線之後繪製。深色主題使用較亮色調，圖例同時標示近期為粗線。
- 選定片段後，歷史全線以該片段首日收盤為 100，近期以近期首日收盤為 100；同一 Y 軸、同一比例尺。沒有選定片段時，歷史以第一筆有效收盤為 100。圖例明示目前基準，沒有分別拉伸曲線去製造相似。
- X 軸為完整市場交易日序列，軸端點顯示目前可見日期；近期第 1、2、…、N 日對齊所選片段第 1、2、…、N 日，粗線到片段末日便停止，不向後虛構近期未來行情。市場休市不增加點數；缺價、異常行情與未成交日保留位置並中斷歷史線。
- 游標移至線圖可核對歷史原始日期、收盤及指數值；在疊線區間也顯示對應近期資料。這是日線收盤走勢，未提供盤中或 K 線重建。
- 零結果會清除近期疊線並回到全部歷史，歷史線仍可瀏覽；切換資料才更換整份歷史。變更設定但尚未重跑時，圖仍屬於有明確標記的前次結果。主題／語言切換保留所選片段及目前瀏覽位置。
- 圖表的後續歷史行情僅供檢視，全部相似度與排名仍只使用各自比對區間內的資料。

## 日級快取與單股資料

本機按日期判斷已有行情及已驗證的市場日曆；已完整保存的請求範圍直接使用本機資料。TWSE 的日線與日曆端點按月回傳，因此缺日會合併成缺漏月份，每月只請求一次；月回應內重複的有效日線不增加重複列或覆寫。月回應會保留該月已完成資料，不早於股票上市日、不晚於台灣昨日，因此本機資料可能比輸入的下載日期更廣。已確認的休市日不當成行情缺漏；有交易但缺行情的日期會繼續補抓，明示停牌／未成交則保留原狀。

每支股票在行情清單只保留一份有效資料，擴大日期範圍合併補齊，不因縮小查詢裁掉既有資料。更新原子寫入；下載失敗或取消保留先前完整檔案。舊版本同股的多份下載檔只在驗證及成功合併後移到備份區。

不同月份中間尚未下載的日曆不能當作「沒有交易日」；缺口仍保留為未驗證，補齊前限制研究。原價可比性缺口、公司行動／不比價邊界及來源診斷不能因資料合併而消失。完整合併行為與本輪驗收結果記於 [006 實作紀錄](HISTOLENS-IMPLEMENTATION.md)。

## 十項可選指標與分數

每個窗口第 i 日的收盤為 Cᵢ，第一日為 C₀，末日為 Cₑ。相對收盤路徑 pᵢ = Cᵢ / C₀ − 1。以下百分率在引擎內用小數表示，0.05 等於 5%。

| 分項 | 比較內容 | 差異 d | 尺度 s |
| --- | --- | --- | --- |
| 價格路徑 | 以起始收盤正規化的整段每日路徑 | 兩組 pᵢ 差的均方根 RMSE | 0.05（5 個百分點） |
| 相對高點 | 末收盤距窗口最高價，Cₑ / max(H) − 1 | 兩個指標的絕對差 | 0.05 |
| 相對低點 | 末收盤距窗口最低價，Cₑ / min(L) − 1 | 兩個指標的絕對差 | 0.05 |
| 趨勢斜率 | 對 pᵢ 與交易日序號 0…N−1 做最小平方直線迴歸 | 兩個斜率的絕對差 | 0.05 / (N−1) |
| 波動度 | 窗口內 N−1 個每日簡單收盤變動率的母體標準差，不年化 | 兩個標準差的絕對差 | 0.02（2 個百分點） |
| 區間 RSI | N−1 次收盤變動的漲跌動能比例，100 × 平均上漲 /（平均上漲＋平均下跌絕對值） | 兩個 RSI 值的絕對差 | 20 RSI 點 |
| 均線乖離 | 末收盤 / N 日收盤算術平均 − 1 | 兩個乖離率的絕對差 | 0.05 |
| 布林帶寬 | N 日收盤上下各 2 個母體標準差，帶寬 4σ / 均價 | 兩個帶寬比例的絕對差 | 0.10 |
| 正規化 ATR | 區間內 N−1 個真實振幅的算術平均 / 末收盤 | 兩個正規化振幅的絕對差 | 0.02 |
| 成交量形態 | 每日成交量 / 區間平均成交量所形成的整段路徑 | 兩組相對成交量的 RMSE | 0.5 倍 |

高低點包含窗口首末日，與舊模板的「事件日前 N 日」不同。斜率顯示單位是「百分點／交易日」。原始收盤價與整段漲跌另列於明細，原價金額不直接參與跨年代價格路徑評分。

```text
單項相似度 = 100 / (1 + d / s)
總相似度   = 已勾選項目相似度的算術平均（每項權重 1 / 已勾選數）
```

差異為零時單項為 100，差異等於尺度時為 50。固定尺度是公開的敏感度設定，未經投資成效校準。價格路徑、高低點與斜率有資訊重疊；等權不代表指標互相獨立。增加勾選項目會改變比較重點，不代表準確度必然提高。

分數為有明確公式的 0–100 相似程度，UI 依使用者習慣標 `%`，不表示上漲機率、預測信心或投資報酬。目前 10 項皆可選；沒有個別權重編輯器。預設原五項仍各占 20%，維持既有預設分數。

### 新指標的區間口徑

新項目由常見動能、均價、振幅與量能概念選出，以下為本產品用於「兩個有限區間比較」的工程定義，並非宣稱已校準的預測模型。N 為使用者指定的近期交易日數，歷史窗口使用相同 N：

- 區間 RSI 採 N−1 次變動的初始平均，不沿用區間外的 Wilder 平滑狀態，也不是固定 RSI(14)。只有上漲為 100、只有下跌為 0；全部平盤定義為 50。
- 均線乖離取 N 日 SMA 末端位置，不使用絕對價格金額作跨年代距離。
- 布林帶寬使用母體標準差、上下各 2σ；全平盤帶寬為 0。
- 真實振幅 TRᵢ = max(Hᵢ−Lᵢ, |Hᵢ−Cᵢ₋₁|, |Lᵢ−Cᵢ₋₁|)，從區間第二日開始。ATR 使用 N−1 日初始平均，不讀區間外前收盤、不延續外部平滑，再除以末收盤作價格正規化。
- 成交量形態以區間平均為 1，量的整體倍數不改變形態。明細末日相對量只是可閱讀的摘要，分數仍比較全部 N 日；未勾選此項時不因缺量排除窗口。勾選後需每筆成交量存在且非負；個別日為零可用，全窗均量為零則無法計算。

### 指標來源與本產品調整

查證日期：2026-10-03。指標概念與公式採金融機構自行發布的說明；相似度尺度、窗口初值、缺值政策及全平盤慣例由本產品明訂：

- [Fidelity：RSI](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/rsi) 說明漲跌動能比例公式；本產品限定在比較窗口內初始化，平盤取 50。
- [Fidelity：SMA](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma) 說明指定期間的算術均價；本產品比較末收盤對均價的相對乖離。
- [Fidelity：Bollinger Band Width](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/bollinger-band-width) 定義上下帶差除以中線；本產品採 N 日母體 σ 與 2σ 帶。
- [Fidelity：ATR](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr) 列出考量跳空的真實振幅及 Wilder 遞迴式；本產品使用有限窗口的初始平均，再除以末收盤，不宣稱與帶長期平滑的固定 ATR(14) 相同。
- [Fidelity：成交量分析](https://www.fidelity.com/viewpoints/active-investor/stock-volume) 說明量能與價格趨勢的關係；本產品據此增加平均正規化成交量路徑，以 RMSE 作形態相似度，該評分方式是本產品設計。

## 門檻、排序與合併

1. 對掃描區間內、早於近期基準的所有完整窗口進行品質檢查。
2. 只計算有效窗口，依未四捨五入總分判斷 `總分 >= 門檻`。預設 60%，剛好 60% 也符合；門檻 100 會保留總分剛好 100 的有效片段，再依既有重疊規則處理。
3. 按總分高到低排列；同分按歷史起日由早到晚，確保重跑一致。
4. 依排序逐一保留，與已保留窗口有日期重疊者合併排除。保留最高分代表片段，不宣称保留片段為統計獨立樣本。
5. 顯示候選、可比較、門檻排除、重疊合併、品質排除及列出數。顯示小數不改變篩選結果；明細可核對公式。

沒有讀取歷史片段之後的价格做挑選或排名；本輪也不新增歷史後續漲跌統計。

## 品質與工作狀態

- 指標勾選保存於目前 HistoLens 資料目錄的 `indicator-preferences.json`，與介面主題偏好分開；損毀或不支援的內容回復原五項。讀寫失敗顯示狀態，仍保留目前勾選及比對結果。全不選也可記憶，但必須至少選一項才可掃描。
- 沿用 `SnapshotValidator` 的來源、日曆、OHLC 與快照雜湊檢查。
- 窗口需要完整有效 OHLC，停牌／缺行情／價格異常排除。公司行動、官方不比價邊界或其覆蓋未知，改為參考及歷史窗口警示；完成未還原原價掃描，不把未知當成沒有行動。圖表標示歷史與近期各自的事件日期、類型及來源，非行情日事件標記不新增 OHLC。
- 基準不完整是阻擋；歷史個別窗口不完整則排除並計數。品質排除依引擎的主要原因計數，不能把缺值補成零。
- 變更勾選指標、近期日數、掃描日期或門檻後，舊结果標記為前次設定；執行中的舊工作不得覆蓋新設定。舊結果的欄位、實值與總分使用該次保存的指標集合，成功重跑後才切換；摘要顯示該次指標數，游標提示列出名稱。
- 取消或失敗保留前次完整結果；換一份資料才清掉相似結果。零符合結果是正常完成，與資料不足或失敗分開。
- 原條件研究的設定、保存格式與引擎仍獨立保留，但進階操作入口已隱藏。相似結果目前可檢視與重跑，未加入舊研究檔格式。
