# MarkPad 開發版狀態

目前版本：**0.1.9**，Windows WPF 可執行開發版。

## 已實作

- 標題列分頁、分頁溢出清單、最近使用分頁切換、分頁重排與跨視窗移動。
- 預設閱讀模式、互斥編輯模式、Markdown 語法色彩、每分頁獨立 Undo／Redo 與位置記憶。
- 搜尋浮窗、大小寫選項、循環搜尋、編輯模式取代／確認後全部取代。
- CommonMark／GFM、表格、待辦勾選、腳註、安全 HTML、程式碼複製與基本語法色彩。
- 標題錨點與折疊、在此編輯、複製 Markdown、本機圖片放大／縮放。
- 圖片貼上／匯入、相對路徑、編碼與 BOM 保留、唯讀／缺檔／大型檔案模式。
- 外部修改檢查、衝突處理、停止輸入 3 秒自動儲存（預設開啟）、崩潰復原。
- 手動展開／收合工具列（顯示功能說明與快捷鍵、記住狀態）、獨立「UI 介面／內文預覽／內文編輯器」字型與字級、Light／Dark／System、英文／繁中／日文。
- UI 字型立即套用到工具列、分頁、選單與設定視窗；介面字級 10–20，內文字級 8–72，三組分別保存且不修改文件。
- 主選單與各層子選單統一使用主題色，包含反白、勾選、停用狀態與分隔線；亮色文件採用原介面灰色，工具列與外框再加深一階。
- 左側工具列使用細圓角捲軸，透明軌道、無箭頭，支援滾輪、拖曳及軌道翻頁。
- 執行檔與工作列使用同一組多尺寸 MarkPad 圖示；工作列標題固定為 MarkPad，文件名稱與未儲存狀態顯示於分頁。
- 操作提示移至標題列下方 24 px、視窗水平中央，方便看見關閉期間的處理提示。
- 修正第一次關閉視窗時同步重入 WPF Closing 的錯誤，完成關閉檢查後排程關閉，無需再點第二次。
- 視窗尺寸入口、F11、同使用者單一實例協調、最近檔案 20 筆與本機錯誤紀錄。
- 「關於」使用置中浮窗，點外側、按 Esc 或按關閉即可收起，顯示版本與作者「不告訴你 Untold」。
- 左側工具列「儲存」下方的「匯出 PDF」先儲存 Markdown，再於原檔旁產生 `原檔名_yyyyMMdd_HHmmss.pdf`（本機時間）；新文件先選擇 Markdown 位置，若同秒出現同名 PDF 則覆寫前確認，取消或儲存失敗即停止。此操作不提供列印功能或 PDF 位置選擇。無文件或匯出中時停用按鈕，收合工具列時保留 PDF 圖示與提示。
- PDF 使用 A4 直式、白底、15 mm 邊界與內文預覽字型／字級；完整匯出表格、換行程式碼、折疊段落及本機圖片，移除互動按鈕與搜尋標記。獨立轉譯不改變目前閱讀／編輯模式，完成後才寫入正式 PDF，失敗保留既有檔案。
- 自訂標題列的最大化邊界依目前螢幕可用區域計算，避免內容延伸至工作列下方；保留最小視窗尺寸、還原尺寸與 F11 全螢幕行為。
- Self-contained x64 可攜版打包、選用的 HKCU 檔案關聯／URI 腳本、第三方授權文件。

產品不呼叫 AI 或雲端服務；文件處理與預覽留在本機。

## 預設偏好（0.1.6）

依使用者 2026-09-22 已儲存的偏好調整，並依後續要求將語言設為跟隨系統。適用於新安裝、重設設定與無效值回退；已有的有效設定繼續沿用。

- 語言與主題都跟隨系統；語言選單保留「跟隨系統」模式，可另外指定英文、繁體中文或日文。
- UI 介面／內文預覽字型依語系自動選擇，內文編輯器為 Cascadia Mono；三組字級均為 16。
- 工具列展開、自動儲存、記住視窗尺寸、程式碼區塊行號及 Emoji 短碼轉換皆開啟。
- 搜尋不區分大小寫；視窗寬 900、高度尚未記錄時使用工作區的 85%。
- 最近檔案清單保持空白，未將使用者的個人檔案路徑納入發佈。

## 目前限制與待驗收項目

- 尚未製作已簽章的 MSIX／Microsoft Store 套件，需正式 package identity、publisher 與商店素材。
- 拖曳分頁、多螢幕混合 DPI、Windows 檔案關聯與 IME，仍需完整人工操作驗收；現有自動測試不代表這些平台情境全部通過。
- 程式碼高亮目前是本機常見語言的輕量 tokenizer，並非完整語言分析器。
- 預覽不下載遠端圖片；本機圖片限文件所在資料夾及其子資料夾，單張上限 20 MB，不跟隨 junction／symlink。
- Preview 搜尋最多標記 20,000 個結果，避免極大量 DOM 標記拖慢閱讀。
- Mermaid 與 LaTeX／KaTeX 依原規格留待 V1.1。
