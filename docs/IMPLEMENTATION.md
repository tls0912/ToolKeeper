# 汗青開發版狀態

目前開發版本：**0.1.19**，已加入啟動正式／試用授權檢查並完成本機自動驗證。原名 MarkPad；Microsoft Store 名稱為「汗青 - Markdown Writer」。

已產生 **1.0.2.0 / x64 MSIX**，位於 `artifacts/msix/Hanqing-1.0.2.0-x64-store/Hanqing_1.0.2.0_x64.msix`；MakeAppx 完整語意驗證與 `Test-MarkPadMsix.ps1` 核對通過，已封入竹材 M 圖示。正式 EXE 檔案版本為 1.0.2.0，「關於」顯示 1.0.2；開發版仍為 0.1.19。舊 1.0.1.0 保留。本次助手未安裝或上傳新包；使用者曾回報 Partner Center 的 runFullTrust 接受度警告，實際提交進度以後台為準。WACK 及真實 Store 授權驗收未完成。

## 0.1.19 啟動授權

- 啟動先核對 Store 套件身分；試用版每次向 Store 查詢，首次確認有效正式授權後保存本機受保護紀錄，同一 Windows 使用者／電腦後續不再查詢。換機、紀錄遺失或失效時重新向 Store 確認；有效授權才進入主視窗、復原草稿、開檔或轉送至既有實例。
- 使用者已在 Partner Center 設定 7 天免費試用；本次未登入後台查驗。期限由 Store 管理，程式不從首次執行日期自行計算七天。
- 無效授權提示購買後結束本次啟動。只有無效授權帶有明確已過期日期才顯示到期，其餘提示沒有有效授權；購買入口開啟產品 `9NHF764PXW9C` 的 Store 頁面，不自動下單。
- 授權查詢失敗或逾時提供重試／關閉，不當成試用到期，也不放行編輯器。離線時使用 Store 回傳的快取授權，不自行設定或延長試用期限。
- MSIX 以 `StoreLicenseRequired=true` 編譯；解壓後的 EXE 缺少有效套件身分仍不能啟動。一般未封裝開發／可攜版略過 Store 查詢；兩種版本各自使用獨立的單一實例識別。
- 檢查範圍僅為啟動，尚未實作使用途中到期時的儲存、購買及停止編輯流程。有效正式紀錄後不再查詢，應用程式不會自動偵測後續退款／撤銷。真實 Store 帳號授權情境與 WACK 尚待驗收。
